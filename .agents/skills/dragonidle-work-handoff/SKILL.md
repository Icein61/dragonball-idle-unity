# 分工与交接

按[项目工作流程](../../../docs/standards/engineering/workflow.md#批次分工与交接)接手。从当前工作树、版本开发单及上一批证据确认任务起点。

- 把已确认范围拆成能够独立验证的工作。按需要分配统筹与策划、程序、配置、素材、测试职责。同一文件指定负责人，互不依赖的检查可以并行。其他代理是否参与遵循任务授权。
- 交接使用这组字段：版本与工作树、负责人和范围、修改或读取的文件、上游依赖、实现默认、已运行的命令及结果、产物路径、待确认或未验证事项、接手动作。
- 统筹检查同一基线和稳定 ID。配置交接带来源与生成差异，素材交接带依赖或预览，测试交接带可重跑命令与实际覆盖。涉及现有玩法或存档行为的决定先确认。
- 合并后核对证据与最终工作树一致，保留开发单的用户原文，按条目更新落地记录和项目状态。
