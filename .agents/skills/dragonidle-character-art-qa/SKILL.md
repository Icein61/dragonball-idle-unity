# 角色素材质检

读[单卡质检规则](../../../docs/standards/character-production.md#单卡质检与验收证据)和该卡的角色表、开发单。按同一时期的参考与已确认素材列出应保持的特征。

1. 将立绘、技能图标、待机、出手、受击、复位和战败按实际游戏比例并列。重点核对身高和体型、肤色、服装、装饰数量、双手或武器朝向、落地线与裁切。
2. 逐招核对发力动作、原定用手、镜像后的方向、锚点、命中停顿、续接和回位。分支招式分别验收。特效覆盖、音频事件和实际结算各有证据。
3. 报告按 `CardId` 和招式记录实画、资源键或裁切、复现条件、问题帧和处理状态。完整有声预览、用户确认、正式接入和后台回归分别登记。
4. 若本批修改须先送审，保留已确认的素材范围，把相关修订合并进一套预览后再交用户确认。当前窗口权限以本次任务和项目规则为准。

原作核对与技能缩略图尺度见[美术规则](../../../docs/standards/art/skill-assets.md)。
