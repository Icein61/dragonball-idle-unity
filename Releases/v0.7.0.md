# v0.7.0 龟仙屋主页预览版

基于已解码素材重设计交互的第一阶段：启动后进入龟仙屋主页，集中剧情准备、人物志、编队、养成、装备、召唤和帮助入口。上方显示实际资源，离线收益可直接领取；声音与显示沿用原设置。

新增深蓝加载页、真实11项界面资源请求进度和筋斗云进度标记；共用金/蓝按钮与返回主页，设置弹窗关闭恢复焦点，保留角色浏览上下文。背景整图等比显示，素材来源/哈希可追溯。

这是分期重设计的首个可用版本。人物志与工坊内部后续统一，挑战/召唤/说明主体仍旧UI；战斗、技能、角色目录和存档规则沿用。1145项核心、资源检查及无图形Player流程验证通过，尚未进行可见画面、实际鼠标操作或试听验收。
