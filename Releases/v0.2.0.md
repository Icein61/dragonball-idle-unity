# v0.2.0 — 角色系统预览版

从8张测试卡扩展至20张原型卡，先建立可持续增加角色的系统。初始及旧版存档获得雅木茶、饺子、龟仙人3张候补，可立即换人配队。

- 角色图鉴、搜索/筛选、技能与被动说明；人物/阶段/形态/称号独立，保留旧CardId。
- 同人物同阶段不同卡可同队；重复抽取只生成对应卡的专属资源。
- 标签队长与覆盖提示、候补换人、3组阵容预设。
- 不同试炼阵容及定向掉落预览；新增技能残页、守势技能解锁、装备收藏筛选与槽位比较。
- 按ID迁移旧存档，迁移前另存独立备份；修复同名防御装备逐件相乘的问题。
- 悟空图鉴/养成页加入一张AI生成静态样片，其余卡片仍是占位表现。

抽卡暂用R72%/SR20%/SSR8%，同级均分，每累计第20抽保证SSR，继承旧抽数。原型卡片、阶段、数值和投放均可调整，未完成长期平衡；不把高稀有度简单做成大幅碾压。

验证：222项核心检查，Windows x64后台构建和实际无图形Player战斗/存档/迁移验证。用户工作期间禁止自动弹窗，本版可见界面、点击操作和演出尚未验收，因此以预览版发布。

完整解压Windows ZIP，运行DragonIdle.exe。无需Unity。存档仍叫profile-v1.json，内部schema已升至2；旧版回退请使用迁移前备份。

不包含：20张正式卡面、3D模型或招式动画、声音、完整逐卡专属机制、重复卡分支、多波副本、长期经济定稿。
