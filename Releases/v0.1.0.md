# v0.1.0 · 战斗核心技术 Demo

## 可玩内容
- Unity 2022.3.62f3 / Windows x64，16:9窗口，可离线运行。
- 7张初始测试卡、1张可抽取测试卡；七人编队、三前四后、队长选择。
- 自动速度时间轴：同刻我1/敌1交替；普通、绝招、怒气必杀；暂停及1/2/4倍演出。
- 前排最近索敌、后排定向绝招、眩晕保护、护盾、治疗、支援、暴击与闪避。
- 同名贡献相加、分别到期；队长独立乘区。
- 四档镜像试炼、通关解锁、自动重复、胜利素材/晶石/装备/珠子掉落。
- 细小修炼、重复卡专属资源与共鸣、三个装备槽、两个额外技能槽、免费镶嵌拆卸。
- 测试召唤：稀有卡8%，其余七卡均分92%；第20/40/60…次保证稀有卡。
- 自动本地存档与上次备份，离线素材领取、首胜任务。

## 使用
下载Windows ZIP并完整解压，运行DragonIdle.exe。必须保留Data目录及附带运行库。
点击“开始挑战”；战斗无需操作。鼠标悬停单位可查看状态。结束后到“养成”“装备”更改配置。
“编队”点击两个位置互换；“说明”领取首胜任务、离线素材或打开存档目录。
空间键/ESC暂停；关闭程序自动保存，正常退出后重新打开可继续养成。

## 范围与限制
这是战斗规则和基础流程的技术切片，不是终版美术或长期平衡版。
角色名与招式用于测试，不代表已选定原著阶段、正式稀有度、最终卡片设计。
没有从dokkaninfo复制/导入素材；该站本次访问失败。画面是程序绘制的临时角色卡与攻击轨迹。
测试卡、招式与经济暂集中于GameData.cs，尚未实现完整数据编辑工具。
额外技能目前仅“专注”和“贯穿气弹”，作为初始测试选项；完整技能掉落池未实现。
本版装备每件1孔，珠子仅攻击强化；完整分支成长、特殊门票副本、多波继承尚未实现。
离线只掉落素材；未实现音乐/正式技能动画、变身、完整主线与任务库。
常规成长2～3小时体感是目标，尚未通过长期真人试玩校准。
