# v0.5.0 — 赛亚人篇角色演出接入版

现有15张卡全部接入C风格立绘和2D战斗小人，每卡12姿态，合计15张立绘、180个姿态。图鉴、角色详情与战场共用对应卡的生产图集。

- 战场使用真实小人出手、攻击、蓄气、受击、闪避、格挡、收招及倒地，保留三前四后与自动行动。
- 19类招式特效区分气功波、螺旋光束、圆盘、念力、斩击、气弹、爆破等；按实际事件反馈多目标、暴击、闪避和护盾。
- 动作时钟支持暂停与1/2/4倍；减少动效抑制突进和高强度装饰反馈。最后一击演出结束后发放奖励，退出/重开清除旧演出。
- 加入4种原创程序合成战斗音，沿用音量与静音设置。
- 保持15卡身份、关键词、队长标签、数值、存档schema3和获取内容；没有新增后期篇章角色。

这是2D关键姿态动画接入版，没有3D/3渲2模型，也尚未达到最终逐帧作画品质。仍需可见画面、真实操作和听感验收；本轮不弹出Unity/游戏窗口，测试静音并使用隔离存档。

资源由imagegen内置工具新生成，没有下载dokkaninfo图；完整来源与提示词见`docs/production/character-art-v050.md`和`Art/Production/V050/prompts.json`。

下载`DragonIdle-v0.5.0-Windows-x64.zip`，完整解压后运行`DragonIdle.exe`。同页附件含`SHA256SUMS.txt`与`build-manifest.json`，记录源码提交与验证结果。
