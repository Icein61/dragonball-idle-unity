# 龙珠爆裂激斗 v0.16.1

## 本地试玩

在 Windows 上完整解压试玩 ZIP，然后运行 `龙珠爆裂激斗.exe`。[Windows x64 试玩包](../Builds/Releases/v0.16.1/龙珠爆裂激斗-v0.16.1-Windows-x64.zip)

- 0006 拉蒂兹以 C 级输出上线，自带手绘立绘、四张图标、2D 战斗动作和本地音效。在编队里可换入候补，战斗 Demo 也会安排他出场。
- 角色列表和详情新增攻、防、生命潜力图。属性显示整数，详情左上角可收藏，问号可查看属性说明及战斗计算规则。
- 比克的反魔爆裂光每回合重新计次。普通闪避和蓄力、群攻均保留次数。闪避会打断对应追打链。
- 悟空的跑步与回位使用统一橙色道服和赤脚姿态。
- 打包前自动写回角色配置表的累计追打状态统计。

## 验证

986 项核心检查、9 张 Unity 后台画面、Windows x64 构建和隔离 Player 回归通过。音频触发和资源读取在静音模式下检验。
