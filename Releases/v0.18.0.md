# 龙珠爆裂激斗 v0.18.0

[版本开发单](../docs/release-plans/v0.18.0.md) · [GitHub 发布页](https://github.com/Icein61/dragonball-idle-unity/releases/tag/v0.18.0)

- 左右数据面板显示伤害、承伤和治疗。伤害和承伤以实际扣血加扣盾计，治疗按实际生命恢复计给施术者。
- 纯数字战斗飘字，扣血、扣盾、治疗及暴击各用独立样式。优化近战接触和追打动画节奏。
- 悟空使用新版地面支撑动作。八位角色均接入修订后的两档浮空、击退、倒地和过渡帧。
- 那巴与栽培人保留角色简表模板。
