# v0.5.3 · 用户设计首批三卡落地

按用户填写的悟空、贝吉塔、比克原稿重构goku-test、vegeta-test、piccolo-test，其余12卡保持独立身份与原机制。图鉴保留四类技能原文，代理数值单独展示；原有CardId、成长、队伍、装备及schema3保持兼容。

- 悟空：正面攻击、自身两机会攻击强化；整场攻击被动，队伍中有任一比克卡即获得整场防御强化，阵亡不取消。
- 贝吉塔：同排攻击强化包含自身；必杀按剩余生命百分比选择敌人；整场攻击与防御被动。
- 比克：同排防御强化包含自身；必杀消耗自身生命（至少保留1）为两名低生命百分比队友加盾；正常行动机会结束自然回复，眩晕也触发，必杀不触发。
- 三张用户概念图接入图鉴，守护必杀使用格挡姿态与友方护盾反馈，不再发射旧攻击光束。既有2D关键姿态保留，没有制作新模型或新增连续作画。

伤害低/中/高默认1.00/1.14/1.30倍；强化低/中4%/8%；中护盾12%受益者最大生命；中生命代价10%自身最大生命；低自然回复3%自身最大生命。以上是代理可调预算，不改写用户描述。未指定招式名暂用蓄势连击/决胜强袭/舍身守护等实现默认。

验证及源码对应见docs/verification/v0.5.3.md和发布manifest。全程后台、静音、隔离存档，可见画面与听感未验收。完整解压龙珠爆裂激斗-v0.5.3-Windows-x64.zip后运行龙珠爆裂激斗.exe。
