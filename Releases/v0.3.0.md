# v0.3.0 · 拉蒂兹来袭预览版
Windows x64，Unity 2022.3.62f3。个人离线Demo，无付费入口。

## 这一版可以玩什么
- 4关“拉蒂兹来袭”章节：首关获取新比克，最终关获取拉蒂兹与聚气核心；首通奖励不可重复领取。
- 共25张卡，14张赛亚人篇卡有不同招式组合。悟空减防牵制配合比克穿防，拉蒂兹双目标攻击；普通攻击仍有意义。
- 独立赛亚人篇召唤池；旧池、原有角色、装备、成长、队伍和保底继续保留。
- C风格悟空、比克和拉蒂兹立绘，接入卡面、小头像和短暂招式特写。

## 启动
下载DragonIdle-v0.3.0-Windows-x64.zip，完整解压后运行DragonIdle.exe，无需安装Unity。
从默认“剧情章节”开始。首关胜利后，去“编队”把“迎战拉蒂兹”比克换入，再挑战后续关卡；也可切换原“素材试炼”刷装备。
旧存档自动按CardId迁移并保留独立备份，不需要清档。

## 验证与限制
430项核心检查通过，包括160场章节模拟与原规则回归。发布流程还会从干净提交重新构建并运行无图形Player测试，结果与源码提交见附件build-manifest.json。
这是入门内容预览；初始赠卡、抽卡与长期成长经济仍是原型数值。基础被动尚未逐卡定制。
美术是AI静态立绘和短暂特写，尚非正式模型/动作动画。未进行可见窗口排版与点击验收，遵守用户工作期间不弹窗的要求。
