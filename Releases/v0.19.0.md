# 龙珠爆裂激斗 v0.19.0

[GitHub 发布页](https://github.com/Icein61/dragonball-idle-unity/releases/tag/v0.19.0) · [版本开发单](../docs/release-plans/v0.19.0.md) · [项目规则与技能](../docs/standards/README.md#项目技能)

## 自 v0.18.2 更新

- 收拢图鉴、编队、战斗入口和存档读写。战斗演出从结算结果及行动前快照读取，沿用已验收的玩法和存档行为。
- 沿用角色工作簿的填法，由工具生成客户端角色、技能和立绘配置。当前为九张上线卡。
- 将 93 项无运行引用的旧资源移出 Unity 运行目录，保留原文件、元数据、校验和与恢复方法。
- 固化角色配表、素材归档、单卡素材质检、分工交接和后台验收五项可复用工作流程。

## Windows x64 与验证

完整解压后运行 `龙珠爆裂激斗.exe`。本版以 v0.18.2 为基线，四个固定种子共 8 场、1,094 次行动的逐步结算结果一致。核心检查、九卡 Windows 无窗口回归和隔离新档验证均已通过。
