# 角色制作与验收流程

从[角色简表](../design/character-rework/README.md)开始，按当前[版本开发单](../release-plans/README.md)安排角色批次。每张卡单独登记 CardId、版本、来源、状态、预览与验证证据。用户原文与代理补充数值或实现默认分别保存。

制作前按[原作优先规则](art/skill-assets.md#原作优先)校对同一时期的造型与招式。出现冲突或关键细节无法核实时，先和用户确认。

## 一张卡的交付顺序

| 阶段 | 工作 | 进入下一阶段的条件 |
| --- | --- | --- |
| 1. 提交设计 | 核对名字、时期、已嵌入的立绘、稀有度、身份标签与投放范围。填写立绘姿势、站立待机、待机小动画、普攻、必杀和追打。技能一至三按需要填写，类型选「被动」或「触发」，不适用的技能填 `[-]`。 | 稳定 CardId 已对应。技能属性写玩家看到的条件、目标、范围、状态、时长和数值。技能描述写动作、轨迹、接触点、特效与声音。额外描述用于解释技能术语。设计空白及待确认处已登记。 |
| 2. 拆解技能规则 | 以九宫格覆盖、手位、怒气和追打链定义验收。列出至少一组正常触发及每个关键例外，例如目标闪避、死亡、空位或插入必杀。补充数值和条件标记为代理默认或待确认。 | 规则和表格有逐项对应。跨排、同名贡献到期、身份标签与队长乘区等适用规则已列出。 |
| 3. 制作立绘和头像 | 从立绘姿势、角色时期、标志性动作和既有制作参考确定表情及轮廓。沿用 C 版手绘漫画风格，立绘与战斗姿态分别输出。先校对人体透视、关节和技能方向，再为构图确定尺寸。效果允许有控制地超框，检查全图、缩略图及文字安全范围。 | 需要用户选图时并列提供编号候选。保存原图、用户选定的实际导入图、对应卡号和预览结果。 |
| 4. 制作招式图标 | 给每项正式招式登记专属 PNG 或图集裁切区域，核对小尺寸识别度。记录角色卡、招式、资源路径及裁切，图鉴和战斗优先共用同一素材。 | 已导入的图标可按路径和裁切读取。需选图时保留各候选和选择记录。暂无图标记录为待补，战斗以技能名显示。 |
| 5. 战斗形象和动作 | 验证 3 渲 2 的可用性，或用通过动作验收的 2D；定脚底、朝向和关键姿势。制作两类待机、入场、接近与撤回的移动、普攻、必杀、追打、适用技能、五种受击与战败。前进绘制交替脚步与衔接帧，以自然跑速和贴地锚点接近。近身命中后默认使用腾空姿态和短弧迅速回到原阵位。带固定外形特征的角色逐帧检查数量和轮廓，例如比克的两根触角。关键帧确定后填过渡帧，核对动作节奏与收招回位。 | 提供逐帧或完整动作预览。跨排贴地、反向镜像和连续受击可检查。制作状态应与实际路线一致。 |
| 6. 特效和音效 | 以掌心、脚底和命中点等锚点接入特效。按配置检查单体、横排和其他范围。逐段登记起手、释放、命中、尾声、落地与取消。音效从用户指定的本机素材库选择，记录源文件、用途、音量和运行事件。 | 特效覆盖及伤害结算分别可验收。音频导入、触发和试听分别记录，缺项明确标注。 |
| 7. Unity 接入 | 按 CardId 接入运行配置、图鉴说明、头像与立绘、姿态、特效、音频和技能名牌。绑定角色自己的资源，保留旧存档、收藏和阵容的读取路径。先接入现有试阵或战斗 Demo。 | 正常操作可以找到角色、选位、开战并观察招式。正式投放范围和可见入口已登记。 |
| 8. 战斗和交付验证 | 运行核心、素材、Windows 构建和无窗口 Player 检查。Unity Play 模式核对 1v1、跨排、空位、满阵、暂停、跳过、减少动效、击退和追打等适用用例。按授权进行画面和听感核对。 | 开发单记录通过项、未验证项和本地包。保留来源、配置路径、截图与源码和包对应凭据。 |

## 同一卡的整套素材确认

同一角色的立绘、图标、战斗形象、动作与特效完成后，合并为一次预览。带上音效和对应时点的记录。用户确认该卡的整套素材后，再接入 Unity 的正式运行路径。按卡跟踪修改意见，收到补充后将修订合入同一套预览。

## 可复用的单卡记录

| 条目 | 最少记录 |
| --- | --- |
| 身份与投放 | CardId、时期、稀有度、身份标签、投放状态、对应版本 |
| 招式配置 | 简表页和单元格、玩家属性、制作描述、运行配置路径、设计或数值默认 |
| 素材 | 立绘、头像、战斗形象、图标裁切、动作、特效、音效路径，及来源和预览 |
| 战斗验证 | 正常用例、边界用例、运行入口、通过或待确认、测试产物 |
| 交付 | Unity 版本、构建路径、与源码对应的凭据、版本开发单位置 |

一张卡达到可交付状态时，应具备玩家可读配置、战斗形象、可播放动作、可辨识技能反馈和可重复的战斗验证。进入正式投放前逐项核对招式图标和素材缺项，保留用户认可的例外。区分「配置完成」「素材预览」「已接入」「验证通过」「可投放」五种进度，按缺项继续推进。

## 追打受击的比例与衔接

- 以同卡待机、战斗缩放和脚底锚点校准受击大小。核对躯干、头部和四肢比例，外框高度随屈身、浮空和倒地姿态调整。
- 各受击轨设置维持帧。等待追打时保留姿势和位置，下一击从当前位置和姿势接续。断链后从当前位置恢复。
- 回归同态和跨态追打、等待下一击、跳过演出和闪避断链。

## 素材候选与接入

- 角色立绘、技能图标或动作表达有多种可行构图时，提供编号候选。根据用户选择逐项绑定正式素材，保留备选和制作提示词。
- 接入前检查四肢、重心、透明边界和色彩，在实际图标、图鉴、场内比例下复查。展示效果用 Unity 捕捉，记录所验收的命中、过渡和终止时点。

## 单卡质检与验收证据

| 检查项 | 实际对照 |
| --- | --- |
| 角色时期与同卡形象 | 对照角色表、已确认立绘和同一时期原作参考。把待机、近身、施法、受击、回位和战败并列，核对身高、比例、肤色、发型、服装、装饰与透视。 |
| 可读尺寸与导入 | 在图鉴卡片和战斗名牌的实际比例查看立绘、图标主体与边框。核对透明留白、图集裁切、左右镜像和脚底基线。按 CardId 跟到正式运行绑定。 |
| 动作、特效与声音 | 按起手、发射、命中、停顿、续接、尾声和归位核对。聚气、弹道、受击点及持招部位使用已确认的锚点。多目标、追打衔接、充能、特殊被动和减少动效等分支按适用场景查看。 |
| 核心与表现一致 | 对照实际结算记录核对每次命中的目标、次数和时点。分别验证动作、效果与声音触发，试听和可见质量独立验收。 |

每项证据带卡号、招式、运行资源、复现入口、问题时点和处理状态。标记用户确认的保留项与批次新内容。需要先送审的角色，用整套有声战斗预览呈现修改结果，确认后再接入正式路径。隔离样片与现行 Player 回归分别记状态。
