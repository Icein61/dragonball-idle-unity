# 角色和界面视觉

- 角色遵循[C 版手绘漫画](../../production/character-style-c.md)。用清楚的轮廓、轻微纸感及两阶阴影保持战场可读性。角色固有色、服装、表情和姿态按单卡时期确定。
- 制作单先并列核对当前简表概念图和已确认的同卡立绘。概念图供时期、动作和表情参考，获准立绘供配色、线条和角色辨识参考。
- 交付状态分别记录立绘、战斗形象、姿态动画、特效、技术接入及可见验收。角色美术完成范围见[确认设计](../../design/confirmed.md)。
- 原创界面沿用雾白、墨青、暖金和小圆角。战斗区保持适当亮度，聚气等题材小组件用于点缀或显示实际进度。统一界面约定见[确认设计](../../design/confirmed.md)。
