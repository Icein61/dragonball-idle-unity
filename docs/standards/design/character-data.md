# 角色配置与回合制

- 以[新版角色简表及坐标映射](../../design/character-rework/README.md)接收设计。角色编号采用现有稳定 `CardId`，同名不同形态分别建卡。改显示名、稀有度或文案时保留编号。
- 普攻、必杀与追打各有独立招式行。技能区分行动型和被动型。C 填一项，B、A、S 填两项。
- 技能属性用于玩家查看，填写目标、触发、效果和数值。技能描述提供动画、特效和音效的制作依据。站立待机和偶发待机独立填写。
- 保留用户填写的技能原文。需要补全触发、条件或数值时，在开发单说明待确认事项。代理默认值写进[默认方案](../../design/defaults.md)，并标明适用范围。
- 当前试阵按[九宫格规则](../../engineering/round-combat-v0130.md)执行。正式配置入库前核对每个状态、目标、手位和存档迁移。演出交由表现层消费战斗事件，命中和伤害由模拟层决定。

## v0.14.0 配置表和概率文字

- 当前填写入口为 [character.xlsx](../../../outputs/character/character.xlsx)。游戏保留稳定 CardId，用表内编号关联制作记录。
- 一定概率为 30%，高概率为 60%，极高概率为 90%。明确写出的百分比按原值。技能说明、标签和实际条件来自配置，旧关键词和绝招替代影响仅用于旧玩法资料。
- 追打上限按卡与回合记录实际出手。多段招式分别列明单发倍率、目标选择、目标不足时策略与每发受击反馈。

## v0.18.1 技能属性分行

技能属性可以用「；」分隔游戏中的描述行，也兼容英文分号。分隔符用于表现层分行。配置编译按同一语义校验各条，保留工作簿原文。技能描述、术语说明和已有换行继续按其用途处理。

## 技能连击字段

每张卡的招式表在 N 列填写技能连击。数字表示当前招式可贡献的连击数。伤害招式的未标注单段默认为 1，纯治疗、被动或复活填 0，分段与多目标按已配置上限逐个记录实击。玩家展示属性原文保留，角色同步工具独立校验本字段。
