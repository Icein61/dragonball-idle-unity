# 初版赛亚人篇角色与队长设计

状态：v0.4.2运行配置，共15张独立卡。仅赛亚人篇为用户确认；逐卡关键词和百分比为可调整默认。保留现有招式和原始身份，未新增模型或动画。

## 统一语义
每张卡2～3个定位关键词，与身份标签分开。共同能力共用词，独特“破绽穿透”对应迎战拉蒂兹比克：目标防御强化为负时，必杀的穿防从10%变25%。关键词是说明，不产生数值效果。
破防指施加减防状态；穿防指攻击时忽略部分防御。先手指开战常驻速度强化，不保证最先行动；加速指招式给予限时速度强化。具体百分比和时长见游戏内技能说明。
关键词总结固有组；更换绝招时会提示原绝招能力不再生效。

每个队长标签均来自本人身份，可为单个，不强凑数量；多标签按任意匹配，多项命中仍仅生效一次。下列数值顺序均为生命/攻击/防御，持续整场；各属性使用独立队长乘区，与普通强化分开。没有队长速度加成。

## 初始、卡池与删除范围
新档8张可用：悟空·重返战场、贝吉塔·孤傲王子、比克·无声守护、克林、悟饭、天津饭、雅木茶、饺子。前七张默认上阵；饺子为候补。比克·迎战拉蒂兹和拉蒂兹仍有章节首通获取。
主赛亚人池15卡；基础常驻池保留旧目录中前20张的赛亚人篇子集共10卡。概率与原双池保底继续保留；同级卡数改变，所以单卡概率随池规模变化。

移除10卡：丹迪·生命的接力、特兰克斯·未来来客、龟仙人·武道传承、超赛悟空·传说觉醒、那美克星篇贝吉塔·不屈野心、内鲁同化比克·守护者的意志、超二悟饭·觉醒的决意、弗利萨·宇宙帝王、人造人18号·无限能量、常态未来特兰克斯·归来的希望。
它们没有运行定义，也不再作为敌人或抽取对象。旧档成长只存迁移归档，装备卸回背包，队伍/预设补位；不把人物或篇章标签改成赛亚人篇。

## 预算与后续
队长总预算小幅分配在生存与攻击，不用Dokkan的大百分比。按角色自身身份组织Z战士、赛亚人军团、地球人、混血赛亚人或那美克星人等队伍，不凭无关种族标签扩大覆盖。现阶段仍为原型数值，长期成长与难度要进一步模拟，不宣称已经完成平衡。
下一步在这15卡范围内逐个完成资源；先做拉蒂兹战悟空的战斗形象、动作和技能特效，再扩展比克和拉蒂兹。当前仅三张C风格静态立绘，美术验收延期。
