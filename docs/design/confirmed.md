## C01 愿景与平台
- 为用户个人制作精美、适合超长期游玩的龙珠题材 Unity 游戏。
- 主要内容：收藏角色、抽卡、组队、刷装备/技能/素材/珠子、任务、副本与持续养成。
- 主要乐趣：对 IP 的喜爱、美术欣赏、新角色获取、配队和搭配更新后的成长反馈。
- Windows PC，16:9 横屏，离线单机，本地存档；关闭游戏后可累计挂机收益。
- 用户可参与编辑器操作，但尽可能少。接受 AI 美术与音乐。
- 前期培养一支主力队即可推进，后期发展多个主题或机制队伍。
- 原著篇章承担主线推进，独立副本承担装备、素材和高难挑战。
- 普通副本不限体力；部分高价值副本有门票或次数限制，细则为默认可调。
- 每个可玩交付版本的源码、规则与对应PC包同步到用户 Icein61 的独立 GitHub 项目。

## C02 美术与演出
- 2026-11-16最新确认：角色形象采用C版「手绘漫画质感」为统一风格基准；线条、色块、排线与肌理沿该样片设计。此项审美选择已完成，不能继续默认切回A/B；2D/3渲2技术实现仍需动作验证。
- 画面为核心质量要求，追求精美手绘感，偏好3渲2但接受高质量2D。
- Dokkan Battle 是风格与体验参考；dokkaninfo及类似站点可供参考，不代表已核验所有数据或取得全部素材。
- 新角色的形象与原著阶段由用户提供参考，具体角色逐个设计。
  - 2026-11-16补充：用户当前无法提供素材，授权代理先寻找参考并制作原型；正式视觉路线仍待样片评估，不因参考缺失暂停角色系统。
- 先比较同角色、同场景视觉样片，再用动作片段验证，之后选择最终2D/3渲2路线。
- 战斗逐次聚焦：每次行动都应有意义，清楚呈现行动者、目标和结果。
- 普攻、绝招、必杀不存在固定强度阶梯；区别来自作用、条件、代价、搭配，不做极端倍率落差。
- 立绘、抽卡与招式的审美目标不等同于已有资产质量或已完成动画。

## C03 阵容、阵位和目标
- 每方最多7名角色，每人独立生命值，阵位三前排四后排。
- 固定阵位具有实际作用，不采用自由移动战场。
- 默认自动索敌：优先最近的存活前排；无可选前排时选择最近的存活后排。
- 默认规则不得仅因后排更近而越过合法前排。
- 特殊技能可攻击对应位置，覆盖默认索敌；等距、空位与特殊目标规则见默认方案。
- 角色默认自动决策，提供角色预设；允许玩家战前修改条件、优先级和目标偏好。
- 常规战斗无基础操作要求，未来新玩法另行讨论。

## C04 时间轴与正常行动
- 全场共享模拟时间；每名角色按速度积累自己的行动进度，到终点后行动并重新计数。
- 开场进度默认为零，特殊效果可以改变初始进度。
- 速度变化保留现有进度，仅影响后续推进速度。
- 演出期间暂停时间轴；本次行动及相关结算完成后才恢复，动画长度/倍速不能改变战斗结果。
- 到达终点时间不同则先到先出手。
- 同时到达终点严格按我方1、敌方1、我方2、敌方2……我方7、敌方7处理；不再以速度或随机决定正常行动的同刻次序。
- 空位、阵亡角色跳过；排队角色出手前复核存活、行动资格与资源。
- 每次正常行动选择一个招式：普攻或绝招。绝招冷却中默认普攻。
- 角色也可由特定高稀有度被动获得特殊行动，具体逐卡定义。

## C05 绝招与冷却
- 普攻、绝招各占一次正常行动。
- 绝招以该角色自身实际完成的正常行动次数冷却，预期通常3～4次，因角色而异。
- 冷却3次示例：绝招 → 普攻 → 普攻 → 普攻 → 绝招。
- 释放绝招的当次不立刻扣除新建冷却。
- 其他角色行动、必杀及额外行动不推进冷却。
- 眩晕跳过行动不推进冷却，不产生出手怒气。
- 可装备替换绝招仍遵循正常行动模型，冷却和效果由技能明确。

## C06 怒气、必杀与插入队列
- 每名角色独立持有怒气，消耗自身怒气自动释放必杀。
- 全新战斗怒气默认0、绝招默认可用；特殊被动/装备/珠子可改变。
- 出手产怒：绝招通常多、普攻通常少；受击产怒少；特殊被动另定。
- 必杀默认不获得出手怒气，特殊被动可以例外；被必杀命中的角色仍按受击规则产怒。
- 必杀不占正常行动，不要求行动条到终点，不重置行动进度、不推进绝招冷却。
- 当前行动完整结算后，先处理满足怒气及策略条件的必杀，再继续正常行动。
- 多个必杀先满足条件者先释放；完全同时按速度高者先，速度也相同则公平随机。
- 上述必杀排序与正常行动同刻按阵位排序是两套规则，不能混淆。
- 队列执行前复核存活、控制、怒气和策略；资格失效不强行释放。
- 必杀可由战前策略保留等待条件，并非怒气满就无条件释放。
- 追击、反击等特殊行动是否产怒须明确；必杀连锁安全边界列入默认方案。
- 多波次/连续关卡继承生命、怒气、冷却尚未逐项确认，使用默认方案。

## C07 属性、命中与防护
- 基础攻击、防御统一；体术、气功等是招式标签，供针对性效果引用，不拆为两套基础攻防。
- 普攻、绝招、必杀默认均可暴击、均可被闪避；特殊技能/被动可改变。
- 防御降低伤害；减伤是额外条件效果；护盾是独立吸收量，通常先扣护盾后扣生命。
- 三类防护可以并存，不要求每个角色都有。
- 防御与减伤避免简单相加轻易完全免伤；特殊无敌/免疫另作机制。
- 命中护盾仍算受击，可产怒和触发受击被动。
- 闪避不算受击，可以触发闪避成功效果。
- 护盾默认不免疫控制、负面状态。
- 受到攻击、实际命中、生命值受损是不同触发条件，描述和实现必须区分。

## C08 控制与持续时间
- 眩晕：不能正常行动或放必杀；进度继续推进，到终点消耗该行动机会并重计。
- 封技：不能用绝招或必杀，正常行动可普攻。
- 减速：降低后续进度推进速度，不倒退已有进度。
- 特殊行动能否在控制下触发须写明。
- 状态默认按持有者自己的正常行动机会计时；眩晕跳过也计数。
- 必杀、追击、反击等额外行动不消耗状态的正常行动机会计数。
- 冷却按实际正常行动、状态按行动机会，两者不能复用同一计数语义。
- 护盾耗尽、下一次攻击等特殊结束条件可以单独定义。
- 防连续眩晕及Boss控制方案属于代理默认，见defaults.md，不标成用户单独确认。

## C09 状态分类与独立期限（最终纠正规则）
- 词条名称对应稳定效果类别。同名有效贡献数值相加，不同类别在相关计算环节累乘。
- 攻击强化和伤害强化为不同类别；增幅、超级赛亚人等未来专属状态也可另设类别。
- 一个类别影响哪些属性/计算环节必须明确；不相关类别不能无条件乘到伤害上。
- 允许同一来源反复施加并累计；不默认设置全局数值叠加上限。
- 每一次加成贡献记录来源、数值、施加时点和独立持续时间，到期只移除该份贡献。
- 未标持续时间的增益/减益默认持续整场；角色被动通常整场，除非明示时长。
- “整场”不是跨战斗永久成长。
- 严禁将同名所有贡献合并为一个最长计时器；整场被动不能让临时强化永久化。
- 旧讨论中的“持续时间取最大”已被用户独立到期的例子取代。
- 普通词条的数值累计不等于带层数的特殊被动；真正叠层/消耗层数机制由特殊被动明示。
- 词条名增加就可能增加乘区，必须谨慎控制类别与投放数值。

### 必须保留的六回合样例
角色被动攻击强化20%整场；装备10%第1～3回合；队友15%第1～2回合；第4回合必杀加15%第4～5回合。
第1～6回合有效加成必须为：45%、45%、30%、35%、35%、20%。
不能变成45%永久、也不能因为第4回合释放必杀额外扣除一次持续机会。
此例回合按受益者自身正常行动机会理解，精确事件相位见默认方案。

## C10 卡片身份、标签与队伍
- 同一人物不同阶段/形态独立成卡；同人物同阶段也可以制作多张独立卡，在不同版本投放。
- 每张卡可以独立立绘、招式、被动、属性、定位；主题称号帮助区分。
- 不同卡可同队，包括同人物同阶段同形态；完全相同的卡不可重复上阵。
- 身份标签包括种族、阵营、阶段等，不能被装备、技能、珠子替换；赛亚人仍是赛亚人。
- 标签限制指使用资格检查，不是装备后修改标签。
- 标签本身不自动提供属性；用作队长技、技能及副本条件。
- 队伍关联来自队长技、标签、技能机制配合。
- 变身细则需单独定义；不能用临时战斗状态偷换身份标签。
- 首次获得卡即有完整普攻、绝招、必杀、基础被动；重复卡用于深化而非补齐基础可玩性。

## C11 队长技
- 所有角色都有队长技，大部分各不相同。
- 七名角色中指定一名队长，占正常位置，仅该队长技生效；所有角色普通被动照常生效。
- 可影响全队或按标签筛选；队长满足条件也受益；任意/同时满足等条件必须明确。
- 基础队长加成开战确定并整场保留，队长阵亡也不移除；特殊条件另行说明。
- 用户明确纠正：队长技是独立专属词条，与普通词条区分，作为独立相关乘区。
- 例：队长攻击加成不并入普通攻击强化。不得恢复旧的“同名就相加”队长解释。

## C12 抽卡与重复卡成长
- 获取节奏介于均衡积累与稀有追求之间；高稀有度更难获得，个人游戏也保留稀缺感。
- 重复获得同一张卡，自动转为该张卡的专属成长资源。
- 同人物不同版本资源不通用。
- 重复卡成长采用固定阶段加少量关键分支，解锁额外技能、改造效果或强化属性。
- 初次卡已有完整基础技能组，不要求先抽重复才能正常游玩。
- 稀有度列表、概率、保底、分支重置与溢出细则尚未逐项确定，代理默认须标注。

## C13 装备、额外技能与珠子
- 每角色3个通用装备槽，专属装备也使用这些槽位；装备可限定使用者。
- 每角色2个额外技能槽。
- 技能刷取同时包括固有技能修炼资源和可装备额外技能。
- 额外技能可提供被动、固有招式强化，特定技能可替换绝招；最多装1个替换绝招。
- 2槽可以都是被动/强化，也可1替换+1被动/强化。
- 替换技能不改变身份标签、普攻、必杀、核心被动；通过人物或标签等条件限制适用。
- 珠子是带技能效果的镶嵌物，装入有孔装备，不占额外技能槽。
- 七人满编最多21件装备、14个额外技能，珠子另计。
- 孔数、拆卸、重复珠机制按defaults.md的可调整默认执行。

## C14 长期成长与数值尺度
- 所有常规成长单次体感细微，累计主动游玩约2～3小时应能感受到区别。
- 这一时间尺度不等于离线2～3小时，也不是每次升级都明显变强。
- 关键强力稀有物品/专属掉落可提前产生明确但有限的提升，保留出货喜悦。
- 修炼资源负责稳定成长，额外技能改变玩法，珠子围绕装备提供精细搭配。
- 不预设必杀一定比绝招强或普攻价值低；战斗应有爽感与平滑难度梯度。
- 总体核算等级、重复卡、装备、技能、珠子、队长与专属乘区，避免单模块合理而组合失控。
- 战斗内越战越强与永久养成分开平衡。
- 具体公式、上限、掉率和稀有关键物的频率需要模拟和实战验证，不能凭文档声称已经平衡。

## C15 当前角色内容范围与稀有度方向
- 当前版本重点设计龙珠Z初期赛亚人篇角色，先围绕拉蒂兹来袭至贝吉塔地球战组织内容。
- 除主角外，角色战力越高或人气越高，稀有度越高；战力结合卡片所属时期判断，不挪用后期成长倒推早期卡。
- 用户未逐张指定稀有度，也未提供人气排名或主角例外的具体形式；这些细则由代理作为可调整默认记录。
- 高稀有度仍受C14长期成长与数值尺度约束；不因此恢复高倍率膨胀或使低稀有度角色失去配队价值。
