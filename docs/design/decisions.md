## 重要替代关系
- 取消Dokkan吃珠战斗；采用速度行动条全自动战斗。珠子是装备镶嵌物。
- 取消必杀占一次正常行动的早期提议；必杀是消耗独立怒气的额外插入行动。
- 绝招冷却3次采用“绝招、普攻、普攻、普攻、绝招”，不是中间只隔两次普攻。
- 正常行动同时到终点不比较速度、不随机；严格我1、敌1、我2、敌2……。
- 多个必杀排序没有被上述正常行动排序替代，仍按就绪时间、速度、随机。
- 同名状态不是取较强效果，而是有效贡献数值相加。
- 同名加成不是共享最长时长；用户最终样例明确每份贡献独立到期。
- 早先“整场强化可使临时强化永久化”解释被明确否定。
- 普通状态数值累计不是特殊被动的层数系统。
- 队长技最初建议与普通攻击强化相加，用户纠正为独立专属词条/乘区。
- 角色标签不会被替换绝招、装备或珠子改变；标签限定是使用条件。
- 同人物同阶段可以多卡，不得用人物+阶段作唯一角色卡标识。
- 成长目标是小幅积累后2～3小时有体感，不是每次强化都显著提高战力。

## 原创 UI 替换解包 UI

用户确认今后改用自主设计的统一 UI。首轮对比暖色漫画、热血分镜、夜色武道三种主页概念稿，按用户反馈收敛为一个方向，再用角色页和战斗界面验证，最后定稿组件规范并分批替换游戏资源。三稿均为设计候选。

第二轮沿「夜色武道」试配淡墨。工作稿采用深蓝、暖金、浅纸色正文和少量朱印。主页用墨色山雾，人物志压低卡片背景纹理，战斗将墨色集中于场景。三屏共用按钮、边框与文字色，墨色浓淡为评审参数。

第三轮试配雾白与墨青。主页保留渐层山雾并加入低对比太极纹，人物志以浅纸卡和墨青选中态区分层级，战斗用雾白交战区与深浅对照的信息板。暖金用于高优先级操作和进度。留白比例为评审参数，布局与纹样均为设计稿。

第四轮接受第三轮的明暗比例和战斗区亮度，撤回第三轮的太极纹和山雾填充。组件评审稿以雾白常态面、墨青选中面和暖金主操作区分视觉层级。工作稿使用薄边、小圆角、文字配合颜色区分危急生命与怒气。聚气环、离线修炼计时和修炼进度为原创示例，优先放在有真实数值的区域，保持战场中央留白。样式尚未接入Unity。

第五轮确认小圆角并开始接入 Unity。主页和挑战页共享代码定义的配色、按钮状态与小圆角。主页使用实际章节和离线收益，战斗环读取画面所处演出时点的怒气。首批替换范围为主页与战斗，启动加载页和其他功能页稍后迁移。
