# 角色美术规范：C版手绘漫画质感

状态：用户已选定的角色视觉方向。基准为[C版悟空](../../Art/Candidates/Goku-Raditz-20261116/C-hand-ink-v1.png)，[生成提示词](../../Art/Candidates/Goku-Raditz-20261116/prompt-C.txt)作为复现参考。此次未重新生成或修改图片。

## 必须延续

- 清楚的外轮廓、带粗细变化和收锋的手绘线；脸部和手部保持干净。
- 以两阶硬边赛璐璐阴影为主，深处有限排线；衣服和色块内部保留轻微颜料颗粒感。
- 鲜明但有节制的角色固有色。橙蓝只属于悟空，不能套用到比克、贝吉塔等角色。
- 保留龙珠Z早期的面部、发型、身材和服装辨识度；强壮不等于统一健美体型。幼年悟饭、饺子、那巴的比例分别设计。
- 角色立绘、头像、卡面共用人物设定和色板；稀有度不改变基础画风。低稀有度角色也必须画得完整精致。

## 生产要求（代理默认）

每张卡先记录CardId、人物、篇章内时间点、服装、形态与技能主题，再制作正面/侧面/背面设定和表情。悟空拉蒂兹战与界王拳时期分别成卡；不把露臂赤足装束当成所有悟空卡的服装。

立绘保留完整头发、手脚与安全留白；出图先看黑白轮廓、小尺寸头像与全身展示。背景、气焰、招式特效分层制作，避免靠大面积光效掩盖角色结构。C样片外围的半透明光晕与紧贴底边的脚部不是要继承的风格特征，正式导入前清理。

优先检查眼睛、指趾数量、关节、头发轮廓、胸背徽记、尾巴、护甲结构和服装阶段。精修必须保持原角色身份，不能用换发色替代新形态设定。

生成新角色时以C作画风参考，以该角色对应阶段的原作资料作造型参考；不要把悟空的脸、肌肉和姿势直接套到所有人身上。所有效果增益文案仍遵守持续时间规则，美术标签不能创造新的数值乘区。

## 比克立绘复盘

- **概念图直接进入生成。** 比克前几轮把旧生成稿当成图像输入，通过文字转述概念图里的动作。改到手指时，表情、肩线和重心也一起漂移。定稿直接把简表概念图作为动作与表情参考，将已认可的上一稿用于手部、线条和配色。
- **把剧情瞬间定成可核对的画面。** 这张卡表现比克替悟饭挡攻击。先对照头部后仰与张口、肩线倾斜、双臂一高一低、双脚前后错开，再查手指、衣褶和透明边缘。仅出镜比克，保持被保护者在画外。闭口凝视改变了剧情瞬间，已由用户否决。
- **逐轮保留用户认可的部分。** 用户认可手部时，手部继续作为明确参考。改变姿势、表情或镜头前，先在概念图上核对对应部位。若同一动作连续偏离，优先用骨架草图或姿势控制先确认结构，再渲染 C 风格；本次定稿采用直接双图参考，未使用外部姿势模型。
- **保留用户确认的原图。** v0.12.2 将 1086 × 1448 透明 PNG 原样接入，界面等比显示全图。
