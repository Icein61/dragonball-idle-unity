# v0.4.0声音来源
原创程序合成，由MenuAudio.cs生成，不依赖外部音频、网络、API或用户素材。
音乐：32秒C大调五声音阶氛围样曲，低音根音/五度加简短拨弦合成旋律。菜单切换不断播；战斗中音量降为菜单的40%。
操作：选择短音、确认上行三音、不可用短下行音。参数集中在MakeUITone与AddNote。
默认总音量65%、音乐18%、音效45%，默认失焦静音。实际最终响度需试听，不把数字音量当作主观音量保证。
程序测试检查非静音有效采样、无NaN/Infinity/超幅；测试时不调用播放，不能据此声称已听过或完成音乐审美验收。
无原著台词或配音，不把合成样曲当作正式配乐。
