# v0.5.1 标志性动作立绘

用户指出v0.5.0立绘姿势过于统一，要求按时期、标志性动作和技能做区分，明确举例元气弹悟空、气圆斩克林。C画风保持。以下为代理据现有卡定义制作的逐卡构图，最终观感待用户验收。

## 构图分工

- 悟空·重返战场：低重心侧身，双手收于腰侧凝聚龟派气功；拉蒂兹战橙色无蓝内衬武道服、赤足。
- 悟空·极限应战：界王拳红色气焰包裹黑发悟空，空中斜向双掌放波；强化高速突进的斜线轮廓。
- 悟空·同伴的希望：双臂高举，蓝白元气弹清晰悬于头顶；强调高耸的Y形轮廓。
- 贝吉塔·孤傲王子：后仰蓄势，双手于肩旁凝聚紫色伽力克炮，保留早期战斗服和黑发。
- 比克·无声守护：双臂横展、迎面挡击，以盾弧表现护盾/援护定位。
- 比克·迎战拉蒂兹：单膝低姿态、双指直指敌人，细光束与螺旋表现魔贯光杀炮；与守护版分开。
- 克林·破局之光：一掌举于头顶托住扁平金色气圆斩，另一拳收于腰侧，身体低伏准备投掷。
- 悟饭·觉醒勇气：儿童比例，腾空屈膝，双掌举额上释放潜力爆发的金色气功；不是改名或新增技能。
- 天津饭·背水之阵：腾空前倾，三角手势对准斜下方，呈现气功炮。
- 雅木茶·狼牙之志：深侧弓步、双指引导操气弹，以弯曲轨迹和目光形成动势。
- 饺子·坚定意志：双足并拢悬浮，手指前伸念力束缚，保持小体型。
- 拉蒂兹·天外来敌：腾空张开双臂，两掌各持能量，长发向后展开，对应双手能量波。
- 那巴·凶悍侵袭：沉重低站姿，一手收拳、一手上挑双指引爆，突出爆破波和压迫体型。
- 亚奇洛贝·关键一刀：矮壮身形侧身压低，双手挥刀作斜向决意斩；使用实体刀刃，不改成能量剑。
- 栽培人·潜伏爪牙：蜷腿腾空扑向前方、双爪前探，少量酸液呼应另一招式，区别于人形站姿。

## 文件与接入

15张1024×1536透明独立立绘位于`Assets/DragonIdle/Resources/Art/V051/*-portrait.png`。完整提示词、参考图、最终输出标识与SHA256记录在`Art/Production/V051/portraits.json`。

全部由imagegen内置工具基于现有C风格形象参考新绘，未调用CLI/API fallback，也未导入网站图片。保留姿态需要的局部能量效果，透明区域由工具生成；检查脚本仅读取像素，不修改图片。

图鉴卡面、详情、养成页与战斗必杀特写改读独立立绘；战斗小人的纹理与UV仍读V050图集。立绘不再从512像素宽的图集侧栏截取，避免每次改卡面时重画动作图。

`PortraitTexture`与`FighterTexture`按不同资源路径缓存；独立立绘整图UV(0,0,1,1)，按2:3原比例显示。V050图集像素、12姿态切图、动作节奏、角色定义和存档结构保持原样。
