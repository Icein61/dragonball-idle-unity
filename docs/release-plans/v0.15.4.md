# v0.15.4 版本开发单

基准版本为 [v0.15.3](v0.15.3.md)。待 v0.15.3 试玩后填写。

## 版本开发内容

本版本目标：

- 新配置
  - 新增角色0005克林
- 新素材
  - 制作0005克林的所有素材，绘制立绘和技能图标的时候多绘制几版由我挑选（素材制作规则）
  - 技能特效制作尽可能精良，可以慢但是质量要高（素材制作规则）
  - 0001悟空、0002贝吉塔移动动画制作并接入
- 新功能
  - 新增角色收藏功能
    - 角色图鉴和角色卡片右上角新增五角星按钮，用于收藏角色
    - 被收藏的角色在同排序下放在所有未收藏角色之前
    - 收藏按钮的大小参照角色图鉴页的稀有度角标
    - 收藏按钮默认无颜色，点击后变为黄色
- UI调整
  - 优化角色卡片中战斗力数值的颜色为绿色
- 优化项
  - 角色卡片右上角快速选择栏
    - 鼠标按住时卡片跟随鼠标滚动，左右预留可超过的空间，松开鼠标后自动回弹至边界

## 版本修复BUG

- 角色专属技能buff用对应技能图标显示，通用buff才显示你设计的图标
- 通用buff描述向技能统一，不使用百分比符号，字体对齐技能中的字体颜色，且连接具体效果和时效的时候不要用符号·
