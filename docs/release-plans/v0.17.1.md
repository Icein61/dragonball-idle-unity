# v0.17.1 版本开发单

基准版本为 [v0.17.0](v0.17.0.md)。本版已完成后台验证，供试玩。

## 版本开发内容

本版本目标：

- 新配置
  - 暂无
- 新素材
  - 不同稀有度的通用背景底图需要加上龙珠元素
- 新功能
  - 新增编队功能，放在角色页签下面
    - 编队页左侧
      - 带透视的九宫格，参考战场
      - 九宫格需要明确格子，为四条*四条的九个平行四边形的格子，放在左侧底部的位置
    - 编队页右侧
      - 角色列表
      - 拖动角色出列表则显示2D小人，松开鼠标小人消失
      - 拖动小人到左侧九宫格的平行四边形区域，将摆放角色到阵位中
  - 修改战场demo的布局
    - 己方为编队保存的阵容
    - 敌方为所有角色库中随机五人随机站位
- UI调整
  - 优化角色能力三维图三角形的颜色改为和稀有度对应的颜色
  - 优化角色能力三维图底边的颜色为淡色，需要和不同稀有度的边的颜色做区分
  - 优化角色主页的三维缩略图中三维三角形边的粗细，缩略图要细，角色卡片也的可以保持现在的粗细
- 优化项
  - 优化角色卡片右上角info按钮的悬浮和点击效果
  - 角色卡片info弹窗
    - 优化窗口UI为圆角矩形，去除窗口上方棕色横边
    - 优化关闭按钮UI，内部图案需要中心对齐，矩形替代为圆角矩形（UI制作规则）

## 版本修复BUG

- 很多角色的被追打状态与其他状态的2D立绘大小衔接有问题，会发生大小突变。注意被追打状态时的2D小人大小、动画衔接（角色制作规则）
- 优化0006拉蒂兹2D小人的体型大小，略微增大
- 优化0002贝吉塔的连续能源弹、0005克林的散射后退特效表现，均略微增大气弹，且气弹命中后增加小幅爆炸和扬尘特效
- 点击角色卡片后，返回角色按钮不应显示被选中的效果
- 快速切换角色卡片的时候，头像框选中效果需要同步当前显示角色卡片
- 点击角色卡片info后弹窗默认选中了关闭按钮
