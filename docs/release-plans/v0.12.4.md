# v0.12.4 版本开发单

状态：已发布，开放收集修订意见。见[发布说明](../../Releases/v0.12.4.md)。

## 版本开发方向（用户填写）

- 本版目标：开发优化角色页签
- 必做内容（按优先顺序）：
    - 角色页签显示内容
    - 角色页签功能便利性
    - 角色卡片展示信息

## 版本详细开发计划【一】
  - 文本修改
    - 人物志->图鉴
    - 全部图鉴->全部角色
    - 全部稀有度->稀有度
    - 全部身份->标签
  - 文本删除
    - 点击角色查看详情....
    - 卡片右上角的阵位信息
  - 组件优化
    - 全部稀有度/全部身份/上阵优先等筛选按钮由点击打开弹窗改为打开下拉框选择
  - 删除按钮组件
    - 战斗定位筛选按钮
