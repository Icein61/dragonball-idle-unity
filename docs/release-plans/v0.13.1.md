# v0.13.1 版本开发单

基准版本：[v0.13.0](v0.13.0.md)。状态：悟空动作、特效与图标已接入 Unity，后台验证通过。

## 版本开发内容

本版本目标：准备九宫格回合制的正式角色设计简表。

- 新配置
  - 保留角色资料与概念图，重做普攻、必杀、追打和技能填写栏。
  - 技能区分行动型和被动型；正式设计留给用户填写。
  - 普攻、必杀、追打和技能分别新增玩家展示的技能属性与动作特效使用的技能描述。
  - 新增角色编号配置
  - 新增角色站立待机动作、待机期间偶尔的小动画的描述，便以后制作角色
- 新功能
  - 暂无
- 素材需求
  - 根据悟空的配置制作2D人物模型
    - 制作站立动作
  - 根据配置表制作悟空的技能素材
    - 制作技能图标素材
    - 制作技能动画素材，动画素材不能少，且需要流畅。可以先给我看关键帧的表现，随后你再优化（素材制作规则）
    - 动画宜长不宜短，希望用低频动画表现技能特点，因此在技能设计的时候我也是每一个技能都会设计的有作用（素材制作规则）
- 文档需求
  - 将项目中的开发规范整理进一个目录，分门别类保存
  - 新增技能素材开发文档要求
- UI调整
  - 暂无
