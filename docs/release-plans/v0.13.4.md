# v0.13.4 版本开发单

基准版本：[v0.13.3](v0.13.3.md)。状态：本地实现完成，后台验证通过，待试玩。

## 版本开发内容

本版本目标：

- 新配置
  - 新建场景配置，配置会选择概念图名，用于绘制场景素材时参考
- 新目录
  - 用于保存游戏中的场景概念图
- 新功能
  - 暂无
- 战斗Demo页签优化
  - 参考真实站位重做战斗模块
  - 站位不再是1v1，而是正常9宫格对战，每个位置上放角色2D模型，并正常索敌战斗、播放动画和特效、计算伤害
  - 目前只做了一个角色，将两边的角色都放在2号位以供测试
- 新素材
  - 音频不要合成中文版，可以去素材来源视频中找，如果未找到合适的标注留白，不要自己合成（素材开发规则）
  - 更新[0001Goku]的音频
- UI调整
  - 图鉴页签/角色卡片
    - 右上角的左右切换两个方形图标缩小，且两个图标中间中间新增方形图标用于展示当前选中角色；图标形成小大小的布局
    - 删除底部选择阵位按钮
