# v0.16.0 版本开发单

基准试玩版本为 v0.15.5。

## 版本开发内容
  这个版本的主要开发目标是基础数值调整，确定数值计算方式、基础战斗节奏；同时会新增一个新角色拉蒂兹
本版本目标：
  和我一起确定角色属性，我说说我的初步设想。
    基础属性有攻击、防御、生命。基础伤害计算方式为攻击方攻击-受击方防御。因此数值设计上攻击需要给的比防御更加慷慨。基础属性随着角色的成长而缓慢增加。
    进阶属性有会心、韧性、穿透、闪避、速度、气。会心提供直接攻击的暴击率，默认暴击伤害为结算伤害*系数1.5。韧性为抵抗暴击的几率，双方的结算暴击方式为攻击方暴击-受击方韧性=最终暴击概率。因此在数值设计上默认的和以后获得的暴击始终要比韧性高一点。穿透则是在攻击时无视对方最终防御的比例，数值不宜给的过高，穿透在设计上更希望在被动中作为稀有度高的强力角色提供。闪避指的是单次受击时的闪避几率。速度则指的是额外命中几率，结算时和闪避属性减算得到最终命中几率修正。气指的是角色获得治疗、护盾的额外提示率。进阶属性根据角色定位给一个初始值，目前的三种角色定位各设计一个初始值，数值根据定位控制在0/5/10。
- 新配置
  - 角色设计表新增带下拉选项的角色各基础属性栏，分别为CBAS
  - 给每个角色1级初始的基础属性值设置一个范围，同稀有度的不同角色之间的基础属性值波动在0.8-1.2；四个稀有度的角色基础属性数值波动为0.7-0.8、0.8-1、1-1.2、1.2-1.5。也就是不同稀有度的基础属性本身就有较大差异，稀有度越高的角色基础属性数值也越高。同稀有度角色之间的基础属性值也有小范围波动。每个角色在设计好后，这些波动值都是不会变的。这项为数值设计，无需写入角色设计表
  - 给每个角色的基础属性等级设置一个等级成长曲线，每个属性均分为CBAS四种。基础属性栏配置的CBAS为该角色属性的潜力，每个稀有度对应一个每个等级的成长幅度，这个幅度可以看成一个导率在不断下降的函数，但是到角色满级100级时仍有一定提升，不会因为导率下降导致无提升。这项为数值设计，无需写入角色设计表
  - 以上两条基础属性的数值设计就会导致不同客户端的相同角色，在每一个等级的基础数值都是相同的、稀有度越高的角色基础属性越高、即便是同种稀有度和同种潜力值的两个不同角色，他们的基础属性数值也会有小幅度不同而并非完全一样。这就是我想要的效果

## 版本修复BUG

- 修复0003比克反魔爆裂光的bug。比克在蓄力阶段受到单体攻击会引发此技能的bug，预期为蓄力时的无法攻击包括无法反击，那么在触发技能判定时检测到无法反击，不满足技能的后段条件，就会直接跳过这次触发。换句话说，比克在蓄力期间无法触发这个触发技。
