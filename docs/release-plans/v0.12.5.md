# v0.12.5 版本开发单

基准版本：[v0.12.4](v0.12.4.md)。继承该单的「版本详细开发计划【一】」，用户原文及逐条结果留在原单。

## 版本开发内容

- 本版目标：优化图鉴页签体验
- 必做内容（按优先顺序）：
  - 新配置
    - 角色设计表新增【类型】字段，预期为输出、防御、援助三个类型
  - 新功能
    - 设计角色战力计算方法，战力数值不要太大，算法需要合适提升不一定要线性提升，但是需要控制战斗力数值的计算方式不要膨胀
  - 修复bug
    - 点击某个角色卡片时，边框显示不全，可能需要调整排版
  - UI调整
    - 稀有图角标左侧需要与角色立绘卡片左侧对齐
    - 角色卡片右上角显示【战斗力：[战斗力]】
    - 角色卡片下方的自我强化/协同防御介绍标签替换为配置表中的【类型】字段
    - 角色页签的筛选下拉栏限制显示数量，最多显示六条内容，下拉框改为可滑动
    - 删除页签右上角的显示内容，改为拥有[拥有的数量]/[图鉴总数量]
