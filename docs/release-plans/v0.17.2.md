# v0.17.2 版本开发单

基准版本为 [v0.17.1](v0.17.1.md)。本版已完成后台验证，供试玩。

## 版本开发内容

本版本目标：

- 新配置
  - 新角色0007雅木茶
- 新素材
  - 制作0007雅木茶的全套素材并接入
  - 不同稀有度角色卡片通用背景地图新增龙珠元素，除了当前的四星球，再加入其他七颗龙珠，不规则排列，其他龙珠大小也不规则，但是小于四星球
  - 制作素材时依旧遵循细工出慢活的原则，可以多做一些素材图供我选择（素材制作规则）
- 新功能
  - 编队页右侧角色列表卡片单机显示角色卡片窗口，参考角色页的卡片制作UI，显示角色基础属性和技能，可滑动查看
  - 编队页新增保存按钮，不点击保存的编队不会被记录下来
- UI调整
  - 编队页
    - 删除左下角UI
    - 右侧角色列表的卡片删除阵位显示
    - 删除右上角战斗demo
    - 删除左上角显示
- 优化项
  - 编队
    - 拖动角色时鼠标指针停留在哪个阵位的四边形范围内，角色被摆放在哪个位置
    - 拖动角色到某个已经放置了角色的阵位时：如果当前拖动角色原先也在队伍中，则交换两个角色阵位；否则替换原阵位角色
    - 鼠标指针点击某个阵位四边形按住不放则选中当前阵位小人，可后续拖动。选中和摆放的时候依据是鼠标指针位置的阵位四边形，而不是2D小人模型

## 版本修复BUG

- 暂无
