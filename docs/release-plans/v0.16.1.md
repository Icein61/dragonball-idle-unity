# v0.16.1 版本开发单

基准版本为 [v0.16.0](v0.16.0.md)。

## 版本开发内容

本版本目标：

- 新配置
  - 每个角色的配置表中新增字段，计算截止当前编号的造成/衔接小浮空、大浮空、倒地、击退状态的技能数量，每次小版本打包前自动维护（配置表规则）
  - 新角色0006拉蒂兹
- 新素材
  - 制作0006拉蒂兹的全套素材并接入
- 新功能
  - 角色卡片战斗力UI向下移，上方新增三维图，类似那种六边形能力值图，但是只有攻击防御生命三维，每维分为CBAS四个等级
- UI调整
  - 角色能力值显示向下取整
  - 角色能力值的进阶属性不显示百分号
  - 角色页显示的每项值右上角新增小问号info按钮，点击在对应位置弹出气泡且背景变暗，介绍该项属性的作用
  - 角色页移动收藏按钮至页面左上角
  - 角色页右上角新增小问号info按钮，点击弹出居中可滚动弹窗，介绍角色之间的伤害计算规则
- 优化项
  - 暂无

## 版本修复BUG

- 0003比克的反魔爆裂光仍有bug，迟迟修不好，因此我在这里扩充相关逻辑
  - 闪避、闪避反击类技能在回合开始时结算触发次数
  - 闪避、闪避反击类技能触发成功后触发次数-1
  - 闪避会中断敌方追打链。例如敌方普攻起手触发了追打状态，敌方队伍有能够追打的角色，这种情况闪避触发时则敌方普攻无法造成伤害、敌方当次追打和后续追打无法衔接，由于没有追打链接上，也不会消耗敌方追打次数
  - 所以比克这种闪避的触发情况为，每回合开始时技能触发次数=1，普通闪避不会消耗次数，蓄力时被单体攻击命中不满足条件触发技能不会消耗次数，被aoe技能命中不会触发技能不会消耗次数，不处于蓄力状态且被被即将单体技能攻击，触发技能的闪避和反击，技能触发次数-1。不管上回合技能是否触发，当前是否处于蓄力状态，技能触发次数在回合开始重制为1，且每次即将受到单体攻击独立计算技能触发条件、剩余次数
- 0001的移动动画和小人模型bug，服装不对
