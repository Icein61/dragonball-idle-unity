# v0.13.5 版本开发单

基准版本：[v0.13.4](v0.13.4.md)。状态：本地实现完成，后台验证通过，待试玩。

## 版本开发内容

本版本目标：

- 新配置
  - 创建新的配置表，表中我来配置概念图名，路径对应概念图目录，用于绘制场景素材时参考
- 新素材
  - 尝试从素材视频中提取对应音效，除非实在提取不出来，说明原因和特殊情况（素材制作规则）
- 新功能
  - 暂无
- 表现优化
  - 战斗demo中角色模型缩小，需要能够在铺满9人的情况下看清每一个人
  - 角色的动画需要再抑扬顿挫一点，快的地方该快，慢的地方该慢，目前视觉效果看起来有点太过软绵绵（素材制作规则）
  - 角色素材相关的设计可以使用其他擅长这方面工作的模型（素材制作规则）
- UI调整
  - 战斗九宫格的九个位置不要形成正方形，需要带点透视，稍微倾斜一点，组成平行四边形

## 版本修复BUG

- 图鉴/角色卡片
  - 右上角的左右切换按钮不要显示箭头，而是对应角色的头像
  - 当是图鉴的首尾角色时，应该屏蔽掉对应的左边和右边的切换按钮
  - 角色战斗时候模型的锚点似乎一直在动，不像站在平地的动作，因此看起来很飘
