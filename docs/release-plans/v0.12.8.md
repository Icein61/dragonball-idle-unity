# v0.12.8 版本开发单

基准版本：[v0.12.7](v0.12.7.md)。状态：已发布。[Windows 预览包](https://github.com/Icein61/dragonball-idle-unity/releases/tag/v0.12.8)。

## 版本开发内容

本版本开发点击图鉴或角色中点击卡片后的详情

- 新配置
  - 角色新加配置栏标签，不需要我手动输入，增加配置列填写标签，我通过打勾来选择对应标签
- 新功能
  - 右上角空白处新增快捷切换，显示左右箭头按钮以及左右角色头像框（正方形），头像框的左上角显示小型稀有度角标
- UI调整
  - 将角色的描述字体缩小并取消加粗，淡化描述占据的篇幅
  - 角色的标签内容之间不需要用符号 · 来连接，用圆角矩形包起来，并横向排列显示，直到需要换行
  - 将属性规则排列，显示生命/攻击/防御/速度/会心/韧性/穿透/闪避，属性字段也通过圆角矩形来包裹
  - 取消概览与培养页战前效果、修炼共鸣的显示，并不提供培养入口
  - 修改文本概览与培养->信息
  - 删除角色立绘卡片下方阵位和队长的显示
  - 将稀有度图标左侧对齐信息显示区域左侧
  - 将稀有度图标右边内容替换为【类型】字段

## 版本修复BUG

- 角色页签筛选的下拉框右侧的滑动条滑动时显示会超框
