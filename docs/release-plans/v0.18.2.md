# v0.18.2 版本开发单

基准版本为 [v0.18.1](v0.18.1.md)。

## 版本开发内容
  v0.18这个小版本需要完善开发中各种规范，加快后续开发效率。
  前面我们做了角色、编队，这个版本的开发重心在战斗玩法上，包括战场、战斗属性、战斗逻辑、战斗动画和特效、战斗节奏、伤害计算和显示等等内容，形成较为完善的游戏最基础的三个模块，为后续各种功能打好基础。
  除此之外加入2位赛亚人篇新角色，0009那巴和0010栽培人。
  开发过程中有任何不确定的地方认真反复找我确定。
本版本目标：
  统一并优化技能图标的显示；重制指定素材；新增连击系统
- 新配置
  - 角色设计配置表
    - 新增技能连击字段
- 新素材
  - 技能图标新规则（素材制作规则）
    - 参考0002贝吉塔、0004悟饭的技能图标大小、技能边框、图片分辨率、美术风格
    - 技能图标改为技能边框和技能图片两部分，默认技能边框采用0002贝吉塔和0004悟饭的样式
  - 角色立绘新规则（素材制作规则）
    - 将角色的人物整体篇幅控制在一定范围内，参考0001悟空、0002贝吉塔
    - 角色立绘展示全身
  - 重新绘制比克立绘
  - 优化拉蒂兹立绘比例
  - 优化0001悟空、0003比克、0005克林、0006拉蒂兹、0007雅木茶、0008天津饭的技能素材
  - 栽培人素材全部重制，和原作形象接近了，但是和目前美术风格严重不搭
  - 素材接入新规则（素材制作规则）
    - 各追打状态持续时长固定，各追打技能动画持续时长固定
- 新功能
  - 新增连击系统
    - 某侧攻击时根据技能的连击数技术，直到另一侧出手计数归零
    - 每段连击造成一段音效
- UI调整
  - 攻击时在攻击侧显示连击数，直到计数归零
- 优化项
  - 追打状态收尾衔接下一次遭受追打攻击，追打攻击动画衔接被追打状态的末端，不要保留单个追打状态末端停留
