# v0.13.2 版本开发单

基准版本：[v0.13.1](v0.13.1.md)。状态：本轮实现与后台验证通过。

## 版本开发内容

本版本目标：

- 新配置
  -新增角色标签【劲敌】
- 新素材
  - 参照项目素材制作标准[0001Goku]的各种受击和状态素材，包括站立、击退、小浮空、大浮空、倒地。受击这几个状态持续时间不长，但是状态之间的过渡需要自然，因为在进入某个状态后可能受到对应状态的追打进入下一个状态，并且可能从状态A被攻击到状态A。（素材制作规则）
  - 参照项目素材制作标准[0001Goku]的进场和战败素材
  - 根据对应技能制作[0001Goku]的音频素材，尽可能参考原作音频，包括特定技能语音、打击音效
- 新功能
  - 实现战斗模块
    - 根据编队站位、角色2D模型、战斗动画特效、战斗音频、战斗逻辑等内容实现战斗模块
    - 初期可以实现一个1v1的战场demo，因为目前只有[0001Goku]有正式资源。
    - 实现战斗暂停功能
- UI调整
  -新增主菜单战斗demo页签用于测试角色的效果

## 承接事项（代理建议）

以下按建议顺序列出。确认本版范围后再写入「版本开发内容」或「版本修复BUG」。

1. 核对 v0.13.1 试玩反馈。重点看悟空待机和四项招式在实际九宫格里的可读性、动作与血量刷新时机，以及暂停和跳过体验。有明确问题后补复现、预期和验收结果。
2. 根据[角色设计简表](../design/character-rework/README.md)核对悟空的正式技能。待明确普攻造成倒地的概率、扫堂腿与追打条件的关系、「劲敌」类别归属和第二技能。沿用已确认的招式原文和稳定编号。
3. 按正式设计的填写进度选择下一张卡。复用已验证的 2D 动作接入流程，先给素材预览，再接入试阵验证。
