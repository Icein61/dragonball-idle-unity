# v0.14.3 版本开发单

基准版本：[v0.14.2](v0.14.2.md)。状态：已完成本地构建和验证，待试玩。

## 版本开发内容

本版本目标：

- 新配置
  - 新增角色0003比克
  - 技能为【被动】时入场触发，技能为【触发】时入场不触发，触发时机满足的时候触发，且同样显示技能图标和技能名
- 新素材
  - 制作角色0003比克完整素材
  - 接入0003比克音效
- 新功能
  - 角色战斗时候的移动由平移改为播放动画，设计角色素材的时候需要设计移动素材（素材制作规则），0001悟空和0002贝吉塔的素材后续版本制作
- UI调整
  - 技能描述不显示大中小括号本身
- 优化项
  - 0002贝吉塔立绘依然有透视问题，参考配置表的字段的新姿势重新设计贝吉塔立绘

## 版本修复BUG

- 战场demo需要中心对称，若目前已是对称则忽视
