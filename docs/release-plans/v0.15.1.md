# v0.15.1 版本开发单

基准版本为 [v0.15.0](v0.15.0.md)。开发已完成，Windows 试玩版已通过后台验证。

## 版本开发内容

本版本目标：

- 新配置
  - 新角色0004悟饭
  - 0001悟空追打更新
- 新素材
  - 素材制作不走Q版风也不走写实风，走系统的立绘绘画风格，但是重点在技能，剩余内容不必详细，保留角色关键特征即可（素材制作规则）
  - 制作角色0004悟饭完整素材
  - 接入角色0004悟饭音效
  - 按照新规则重新绘制0002贝吉塔连续能源弹和赛亚精英的技能图标
- 新功能
  - 暂无
- UI调整
  - 角色卡片
    - 稀有度图标等比调大，高度对齐右侧切换图标
    - 删除信息页的“回合制属性预览”
    - 技能页UI布局调整，单个技能由圆角矩形包裹，最左侧是图标，右侧上方是技能名，下方是技能描述。技能描述用可滚动的圆角矩形包裹，同样上下方预留可以拖动过头的窗口并自动回弹。项目中所有的可滚动组件都改成这种方式（UI组件制作规则）
- 优化项
  - 角色卡片的技能查看滚动的时候，上下拉动过头的窗口略微增大
  - 减慢0003比克反魔爆裂光技能闪避、反击动画的速度，给玩家一个反应时间，并类似必杀给镜头特写

## 版本修复BUG

- 暂无
