# v0.15.0 版本开发单

基准版本为 [v0.14.5](v0.14.5.md)。已完成本地构建与后台验证。

## 版本开发内容
  0.15版本将会将开发重心聚焦在图鉴系统的体验优化上并新增角色系统；同时追加新角色孙悟饭【幼年】、克林
本版本目标：

- 新配置
  - 新增两位新角色的模板，我将会正式制作角色之前填写设计
  - 角色设计表新增角色序号字段
- 新素材
  - 贝吉塔的连续能源弹和赛亚精英图标继续修改
    - 连续能源弹图标透视有问题
    - 赛亚精英取消Q版设计，重绘
  - 技能图标绘制不用Q版，和角色立绘、动作一样，需要格外注意透视问题（素材开发规则）
  - 技能图标绘制使用写实风，但是可以模糊非重点表现，仅保留人物重要特征，重要的是技能本身，不能舍本逐末（素材开发规则）
- 新功能
  - 图鉴新增按序号的排序方式
- UI调整
  - 图鉴
    - 取消我的角色和全部角色页签
    - 将图鉴页分为已拥有和未拥有两部分，中间使用合适的表现方式换行隔开
    - 未拥有部分的角色立绘显示灰色，同时UI颜色适当调整
    - 搜索框、筛选栏中字未居中对齐
    - 将图鉴页的图鉴标题移到上方，替代角色收藏字眼，下方UI整体上移
    - 角色卡片页右上角切换角色整体布局略微调大
    - 角色卡片页角色名和名字下方的描述往上移，移动到稀有度标右侧，同时下发UI整体上移
- 优化项
  - 角色卡片页招式改为技能
  - 角色卡片的技能查看滚动的时候，可以适当上拉或者下拉过头一点，松开鼠标后自动回弹到边缘，让手感更加顺滑

## 版本修复BUG

- 0003比克释放追打时也是慢跑过去，释放追打的移动动作类似攻击完的后跳，直接前跳即可，不需要播放移动动画。前跳和后跳的速度不要太快，需要给玩家一个反应时间
- 0003比克的技能反魔爆裂光失效
