# v0.15.2 版本开发单

基准版本为 [v0.15.1](v0.15.1.md)。本版已完成开发与后台验证。

## 版本开发内容

本版本目标：

- 新配置
  - 图鉴页使用BGM D:\Projects\dragonball-idle-unity\artifacts\xenoverse2-audio\图鉴与角色系统BGM试听
- 新素材
  - 优化0004悟饭重击动画的蓄力阶段
  - 删除0003比克立绘中的魔贯光杀炮，仅保留姿势
  - 优化0002贝吉塔连续能源弹技能图标，现在看起来两只手的形状都是右手
- 新功能
  - 图鉴页签改为角色页签
  - 从其他位置点击角色页默认打开角色主页而不是上次选中的角色
  - 角色页默认使用序号排序。做本地缓存，每次打开游戏默认使用序号排序，当玩家选中任一排序方式后，将始终为本地记忆的排序，直到重新打开游戏
- UI调整
  - 统一所有角色技能图标的样式，均为正方形
  - 扩大角色技能页签中技能图标的大小，高度对齐右侧技能名上分+一行技能介绍下方
  - 当技能介绍至多显示四行，超出四行的部分需要滑动技能介绍预览
  - 当技能介绍大于一行时，左侧技能图标需要居中显示
- 优化项
  - 放慢0004悟饭重击的动画速度
  - 放大角色卡片中0003比克的立绘，和其他角色同样大小

## 版本修复BUG

- 0003比克的反魔爆裂光后续回合不会触发
