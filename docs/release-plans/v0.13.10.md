# v0.13.10 版本开发单

基准版本：[v0.13.9](v0.13.9.md)。状态：v0.13 收尾完成，本地 Windows 试玩包已验证。

## 版本开发内容
 - 总结0.13版本开发过程中的经验
 - 将角色制作流程规范化，包括填写配置表，制作技能图标、立绘、动作、特效、音效等各种素材，测试战斗等流程，直到一个角色真正的落地
 - 收尾0.13版本，之后进入到0.14

## 本版本目标：

- 新配置
  - 暂无
- 新素材
  - 暂无
- 新功能
  - 暂无
- UI调整
  - 角色入场被动技能和必杀技释放时的技能图标和名字
    - UI缩小，背景色类比状态栏，且在角色附近固定位置，不要晃动
    - 技能图标读取为角色制作的技能图标素材，不要临时新建
- 优化项
  - 0001Goku的必杀龟派气功，尾部有点细需要略微加粗

## 版本修复BUG

- 0001Goku释放必杀时的特写bug，镜头没有正确复位。期望效果是释放必杀时镜头平滑拉进到特写位置，必杀结束的时候平滑地恢复释放前的位置，且镜头变化幅度不要大。
