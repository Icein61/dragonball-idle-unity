# v0.18.1 版本开发单

基准版本为 [v0.18.0](v0.18.0.md)。已收到 v0.18.0 试玩反馈。

## 版本开发内容
  v0.18这个小版本需要完善开发中各种规范，加快后续开发效率。
  前面我们做了角色、编队，这个版本的开发重心在战斗玩法上，包括战场、战斗属性、战斗逻辑、战斗动画和特效、战斗节奏、伤害计算和显示等等内容，形成较为完善的游戏最基础的三个模块，为后续各种功能打好基础。
  除此之外加入2位赛亚人篇新角色，0009那巴和0010栽培人。
本版本目标：
  继续优化战斗和战场环节。核对v0.18.0我新增未完成的部分。
- 新配置
  - 新角色0010栽培人
  - 新增规则，角色配置表中技能属性栏用分号；分割游戏中UI的描述行
- 新素材
  - 制作0010栽培人的全套素材
- 新功能
  - 暂无
- UI调整
  - 战斗数据统计页
    - 总体设计为圆角矩形
    - 每行分为头像框和数据
    - 头像框参考角色卡片右上角快速切换
    - 数据部分为条形图，数据最高的铺到UI边缘，其他数据等比调整长度
    - 数值数字显示在数据条的中心
    - 伤害、承伤、治疗三种数据分别为红色、蓝色、绿色
    - 删除数据显示上方的我方数据和敌方数据描述
- 优化项
  - 暂无

## 版本修复BUG

- 0001悟空普攻的时候依然飘，可能需要固定角色锚点位置不变
