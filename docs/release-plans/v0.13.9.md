# v0.13.9 版本开发单

基准版本：[v0.13.8 有声版](v0.13.8.md)。状态：本地 Windows 试玩版已验证。

## 版本开发内容

本版本目标：

- 新配置
  - 暂无
- 新素材
  - 必杀释放时需要一个特写，一瞬间的背景变暗且镜头略慢，之后迅速恢复
  - 制作通用入场类被动技能特效，类似追打，但是颜色、光效闪过的速度和音效上做区分 
- 新功能
  - 角色入场技能触发播放对应特效
- UI调整
  - 删除战场底部的九宫格线
  - 角色触发入场被动技能、必杀时需要在附近显示技能图标和技能名
  - 角色的状态条外侧的边框也改为圆角矩形、上下左右等距、背景颜色尽可能淡
- 优化项
  - 0001Goku必杀龟派气功贴手端切割感严重，光波类的特效边缘应该是圆润的
  - 0001Goku必杀龟派气功斜着了，期望是水平的，且长度过短，达不到攻击对面横排的视觉效果，制作技能特效的时候需要考虑配置中的攻击范围（素材制作规则）
