# v0.15.3 版本开发单

基准版本为 [v0.15.2](v0.15.2.md)。开发与后台验证已完成。

## 版本开发内容

本版本目标：

- 新配置
  - 将角色页的bgm用于角色、编队和主页
- 新素材
  - 0002贝吉塔连续能源弹技能的图标中手部绘制依然有问题，可以采取其他视角，或者弱化手部表现重绘多张图片并编号，我挑选指定的一张接入
  - 优化0004悟饭2D小人模型和立绘的发型，目前版本有点像西瓜头那样整齐，实际上更加凌乱，可以参考技能视频中的形象
  - 设计并绘制需要显示的buff图标
- 新功能
  - 新增战斗时显示buff的功能
    - 显示buff的范围：角色常驻被动、限时增益/简易、技能中的特殊状态（使用中括号标起来的，比如蓄力）
    - 显示buff的位置：在状态栏内部，角色怒气条下方，以小型圆角正方形显示
- UI调整
  - 略微放大角色卡片页右上角快速切换角色UI的大小，且左右可切换角色提升至最多两个
- 优化项
  - 角色卡片页右上角快速切换角色UI需要支持鼠标拖动切换

## 版本修复BUG

- 0003比克魔贯光杀炮蓄力时不需要显示在转圈的特效，显示手指部分的光效即可
