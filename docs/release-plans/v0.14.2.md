# v0.14.2 版本开发单

基准版本：[v0.14.1](v0.14.1.md)。状态：已完成本地构建和验证，待试玩。

## 版本开发内容

本版本目标：

- 新配置
  - 角色配置表新增立绘姿势字段，用于描述立绘姿势
  - 角色配置表删除所有概念图，将概念图字段替换为立绘并将立绘以嵌入式方式填进表中。以后设计角色立绘不需要概念图，而是参考
  - 将配置表中前三位角色（0001悟空，0002贝吉塔，0003比克）之外的角色都删除
  - 将配置表中追打状态的中括号【】全部替换为大括号{}
- 视频素材和立绘姿势制作
  - 将技能1、技能2(BAS)改为技能一、技能二、三。技能栏位填写[-]即表示这个角色没有这个技能
  - 技能一/二/三技能类型字段添加可选项两种类型，被动、触发
  - 技能栏新增额外描述字段，用于描述技能中专业术语
- 新素材
  - 暂无
- 新功能
  - 暂无
- UI调整
  - 技能介绍中使用中括号【】包裹的使用橙色字体
  - 技能介绍中使用小括号[]包裹的使用绿色字体
  - 技能介绍中使用大括号{}包裹的使用浅蓝色字体
- 优化项
  - 暂无

- 角色卡片右上角左右切换角色按钮的稀有度角标未显示
- 0002贝吉塔的立绘手部透视有问题，需要冲绘
