# v0.17.3 版本开发单

基准版本为 [v0.17.2](v0.17.2.md)。本版已完成后台验证，供试玩。

## 版本开发内容

本版本目标：

- 新配置
  - 新角色0008天津饭
- 新素材
  - 制作0008天津饭全套素材并接入
  - 优化角色卡片背景图中其他龙珠打的效果，类比四星球做成带点透明和反光的效果，大小不需要变
  - 为输出、防御、援助三种类型制作图标素材，设计理念为红色小人聚气、蓝色小人双拳抱于胸前、绿色小人传递仙豆。
  - 再次强调素材的制作需要精美，慢工出细活，可以多做几版供我选择（素材制作规则）
- 新功能
  - 暂无
- UI调整
  - 角色卡片左上角角色类型放到角色描述之后，采用制作好的角色定位图标素材，高度和角色描述对齐
  - 同步更新编队页的角色卡片左上角UI，替换稀有度图标和角色定位图标，排版为第一行角色名称、描述，第二行为稀有度图标、定位图标
- 优化项
  - 暂无

## 版本修复BUG

- 暂无
