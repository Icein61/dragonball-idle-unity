# v0.13.0 版本开发单

基准版本：[v0.12.8](v0.12.8.md)。状态：已发布。[Windows 预览包](https://github.com/Icein61/dragonball-idle-unity/releases/tag/v0.13.0)。

## 版本开发内容
重构战斗玩法以及相关配置，为后续角色设计重构做铺垫
本版本目标：

- 战斗玩法介绍
  - 5vs[5-9]的回合制战斗
  - 每方战场有3*3的位置，玩家侧可以选择至多五名角色进行组队和站位，敌方ai根据难度和副本特殊性至多可以9位
  - 九宫格位置从上到下从右到左编号1-9号位置，敌人侧则面对面镜像
  - 取消玩家速度属性值，战场出手顺序固定，敌我角色入场时会有一个决定出手顺序的隐藏次序手位，玩家角色先，交替排序，某个角色死亡后其他角色的手位不会变化。
  - 每个角色固定拥有【普攻】【必杀】【追打】【技能】，根据稀有度可能额外赋予技能，BAS级角色追加【技能】，技能可以是带条件的【行动型】，也可以是【被动型】
  - 角色出手指的是使用【普攻】，当怒气满时无视手位直接使用【必杀】，如果同时满足多个角色必杀释放条件，释放顺序再参考手位
- 新配置
  -根据新的玩法和角色设计新的配置表，配置表的格式需要简洁紧凑，所有配置表也按照功能分目录存放，彻底不用的配置表可以删除
- 新功能
  -暂无
- 系统重构
  - 删去暂时用不上的页签和系统，后续会陆续重新开发，包括挑战、养成、装备、召唤，仅需要保留角色和编队
- UI调整
  -根据新的战斗玩法和项目的UI风格，调整编队页的新战场布局
