# v0.14.4 版本开发单

基准版本：[v0.14.3](v0.14.3.md)。状态：已完成本地构建与后台验证。

## 版本开发内容

本版本目标：

- 新配置
  - 更新0001悟空角色标签
  - 更新0001悟空、0002贝吉塔、0003比克配置
- 新素材
  - 制作立绘时需要格外注意透视，不一定限制为目前立绘的范围，如有必要图可以稍微制作大一点，为了视觉效果允许超框（素材制作规则）
  - 制作0003比克反魔爆裂光的触发动画和特效
  - 参考视频优化0003比克反魔爆裂光的反击动画和特效，反击光波应该是向外扩散，表现力需要更猛烈。反魔爆裂光的闪避反击并不是真的普通闪避，逻辑上闪避后反击且不受伤害，表现上分两段，预备动画特效+反击动画特效
  - 更新贝吉塔技能图标，现有图标中的装备和配色与当前时期贝吉塔不匹配
- 新功能
  - 暂无
- UI调整
  - 暂无
- 优化项
  - 0003比克的立绘需要调整。我发现你很不擅长立绘透视，比克的魔贯光杀炮出手时手应该是正向前平举的，并且魔贯光杀炮的特效也是向前平射。优化比克的立绘和特效。
  - 角色向前移动时播放跑动动画，速度不宜太快，需要以自然跑动速度向前
  - 角色向前移动并攻击完后，默认迅速跳回原位置，不需要播放移动动画
  - 在游戏中删除目前配置表中没有的角色

## 版本修复BUG

- 0003比克的反魔爆裂光触发且敌方怒气满时，反魔爆裂光的闪避和反击逻辑会被必杀技中断。期望：触发技优先级>其他技能，且逻辑上不应被中断
- 0003比克很多关键帧的模型触手缺失，不足两个
- 角色闪避追打，敌方追打链断了之后，角色在下一次受到攻击前会保持当前的受击状态。期望：敌方追打链断裂时角色恢复待机状态
- 角色被造成追打状态且敌方无追打技能衔接且地方角色释放必杀时，角色会保持当前受击状态。期望：后续不受到敌方追打的情况需要恢复待机状态
