# v0.14.5 版本开发单

基准版本为 [v0.14.4](v0.14.4.md)。已完成本地构建和后台验证。

## 版本开发内容
  战斗玩法的流程和角色设计的框架基本稳定了，开发完这个小版本后，总结这个版本的经验，进行收尾，并生成下个版本的开发单
本版本目标：

- 新配置
  - 更新角色相关音频库目录为D:\Projects\dragonball-idle-unity\artifacts\xenoverse2-audio\赛亚人篇-角色音频素材库
- 新素材
  - 贝吉塔的技能图标
    - 连续能源弹需要做出两只手交替扔出能源弹的效果
    - 赛亚精英图标没有头部，需要补充贝吉塔的头部，但是脸部用Q版画面替代。角色技能图标稍微Q版比较让人印象深刻（素材制作规则）
- 新功能
  - 暂无
- UI调整
  - 暂无
- 优化项
  - 暂无

## 版本修复BUG

- 0003比克蓄力期间魔贯光杀炮的蓄力特效丢失
- 0003比克攻击时移动动画播放速度不统一，有的时候正常播放，有的时候快到看起来没播动画直接移动过去的
