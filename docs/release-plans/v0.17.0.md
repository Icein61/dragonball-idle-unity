# v0.17.0 版本开发单

基准版本为 [v0.16.2](v0.16.2.md)。

## 版本开发内容
  这个版本的主要开发内容是编队模块，会逐步重新开发一个完整的编队模块；新增角色0007雅木茶、0008天津饭
本版本目标：

- 新配置
  - 新增新角色配置模板
- 新素材
  - 修改C级稀有度角标配色，围绕绿色设计
  - 重新绘制各稀有度的背景图，目前太素且太单调。稀有度越高纹理越华丽，低稀有度角色也需要有一定纹理
  - 优化info图标，背景尽可能透明，仅保留外侧黑色圆型和中间的图标
- 新功能
  - 删除原有编队功能，待后续重构
- UI调整
  - 战力维度图
    - 删除维度后面的CBAS等级显示，三个字体文本框距离最大维度等距，重新排版
    - 删除维度图的黄色顶点
    - 优化维度图斜线的抗锯齿表现
    - 优化维度图不同等级之前的距离，等级越高距离略微增大
    - 优化收藏按钮的位置，对齐返回按钮居中
- 优化项
  - 暂无

## 版本修复BUG

- 角色0006拉蒂兹的技能双重太阳日特效丢失
- 角色0005克林受击时贴图左下角错误地显示了多余的脚部
