# v0.13.8 版本开发单

基准版本：[v0.13.7](v0.13.7.md)。状态：Windows 本地有声试玩包已验证。

## 版本开发内容

本版本目标：

- 新配置
  - 暂无
- 新素材
  - 挑选并接入0001Goku的音效
- 新功能
  - 暂无
- UI调整
  - 站位的数字编号删去
  - 战斗demo左右和下方的战场信息记录删去，被删去的空间由将中心战场扩充，让玩家聚焦于战场
- 优化项
  - 0001Goku的必杀特效过细了，不大改的情况下进行加粗，比抬手聚气时的圆形特效细一点
  - 优化追打触发时的特效，大概为淡淡的白光从下往上瞬间闪过角色的2D模型
