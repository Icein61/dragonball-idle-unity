# v0.18.0 版本开发单

基准版本为 [v0.17.4](v0.17.4.md)。本版集中优化战斗，角色追加延后。

## 版本开发内容
  v0.18这个小版本需要完善开发中各种规范，加快后续开发效率。
  前面我们做了角色、编队，这个版本的开发重心在战斗玩法上，包括战场、战斗属性、战斗逻辑、战斗动画和特效、战斗节奏、伤害计算和显示等等内容，形成较为完善的游戏最基础的三个模块，为后续各种功能打好基础。
  除此之外加入2位赛亚人篇新角色，0009那巴和0010栽培人。
本版本目标：
  与我探讨开发中的各种流程和规范，越详细越好，你问我答。
- 新配置
  - 暂无
- 新素材
  - 重做0001悟空的战斗素材，现在的太飘了
  - 优化目前所有角色的被追打状态的小人素材，且制作各状态间的过渡动画
    - 小浮空参考理念，角色身体略微弯曲正面向下
    - 大浮空参考理念，角色身体弯曲加强正面向下
    - 击退参考理念，角色身体弯曲正面朝向攻击来源侧
    - 倒地参考理念，角色身体朝上
- 新功能
  - 新增战斗数据显示功能
  - 和我探讨战斗数据的计算方式，越详细越好
- UI调整
  - 优化战斗飘字
    - 普通伤害为白色
    - 护盾为蓝色
    - 治疗为绿色
    - 暴击伤害为黄色且字体放大，并且做出额外字体效果
    - 取消战斗飘字的符号、汉字，仅保留数字，且存在时间略微加长
  - 新增战斗数据显示面板
    - 双方角色的数据面板UI显示在战场左右侧
    - 面板UI设计三个子页签，默认显示伤害，点击承伤和治疗可以切换
- 优化项
  - 优化战斗动画落点，攻击方尽可能接触到防御方，因此素材制作时也需要格外注意（素材制作规则）
  - 放慢追打节奏
  - 优化追打状态动画衔接
  - 优化被追打角色与初始位置的相对位置
    - 小浮空，位置略微提高
    - 大浮空，位置进一步提高
    - 击退，位置大幅向后移
    - 倒地，躺倒在地
    - 其中小浮空，大浮空，击退均为相对角色初始位置的固定位置，倒地是相对被追打位置的倒地
  - 优化被追打时角色的位置衔接
  - 略微加快追打节奏，略微放慢追打状态动画之间的衔接。追打状态过渡到一般下一个追打角色需要开始出手，最好追打状态收尾衔接下一次受击，不要保留单个追打状态尾端过久
  - 略微延长0008天津饭气功炮的动画和特效持续时间

## 版本修复BUG

- 0006拉蒂兹闪耀金星日的技能特效会丢失
- 0008天津饭的一指功没有音效和命中音效
