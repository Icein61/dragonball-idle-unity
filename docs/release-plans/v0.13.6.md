# v0.13.6 版本开发单

基准版本：[v0.13.5](v0.13.5.md)。状态：战斗改动已接入，后台验证通过，音效待项目自有素材。

## 版本开发内容

本版本目标：

- 新配置
  - 暂无
- 新素材
  - 将此项列入常驻版本开发单
  - 从音频目录接入0001Goku对应的音效
  - 重制0001Goku必杀的动画和特效，龟派气功的特效应该为圆柱型蓝色光波，到极限距离不应该突然消失特效，而应该看到淡出效果
- 新功能
   - 暂无
- UI调整
  - 绘制角色生命（绿色）、护盾（蓝色）、怒气（橙色）窄横条UI，放在角色阵位对应位置
- 优化项
  - 将此项列入常驻版本开发单
  - 角色的入场被动技能动画时间缩短
  - 角色受击时的锚点位移尽可能小，减小飘感
  - 减慢交替出手轮次的速度，给玩家反应动画的时间

## 版本修复BUG

- 暂无
