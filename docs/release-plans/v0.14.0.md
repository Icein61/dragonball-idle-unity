# v0.14.0 版本开发单

基准版本：[v0.13.10](v0.13.10.md)。状态：贝吉塔和首轮 3v3 已接入，本地 Windows 试玩包已验证。

接手入口：[v0.13 开发复盘](../engineering/v0.13-retrospective.md) · [角色制作与验收](../standards/character-production.md)。

## 版本开发内容
  0.14版本的主要开发任务是制作两个新角色，并在战斗demo中测试不同站位下的3v3战斗是否流畅，包括技能释放、目标锁定、伤害计算、特效表现、追打衔接、音频等多项指标
本版本目标：
  新增角色贝吉塔
- 新配置
  - 修改了角色配置表的文件和路径名
  - 新增了角色0002贝吉塔的配置
  - 更新了0001悟空的追打次数、追打状态
  - 更新配置表中的概率描述的概率，一定概率[30%]，高概率[60%]，极高概率[90%]
  - 废除原规则中关键字和强化失效的规则，依据配置表重新制定
  - 角色设计.xls新增角色标签【下级战士】
- 新素材
  - 根据配置表和对应技能参考视频制作立绘、技能图标、动画和特效
- 新功能
  - 暂无
- UI调整
  - 暂无
- 优化项
  - 删除游戏主页背景音乐
