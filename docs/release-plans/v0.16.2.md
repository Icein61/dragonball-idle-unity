# v0.16.2 版本开发单

基准版本为 [v0.16.1](v0.16.1.md)。

## 版本开发内容
  约定一下版本号的称呼方式：v0.16.1，其中第一个点号之前的是大版本号，随后是小版本号，最后是中间版本号。开发完这个中间版本后金星规则和经验总结，随后生成下个小版本的开发单。
本版本目标：

- 新配置
  - 暂无
- 新素材
  - 为info按钮设计图标，素材需要尽可能清晰
  - 为四种稀有度的角色设计卡片背景图，设计逻辑参考稀有度角标，是尽可能接近稀有度角标的颜色纯色，略微增加一点纹理装饰
  - 重绘0006拉蒂兹技能闪耀金星日的技能图标，目前图中仅有四根手指
- 新功能
  - 为角色卡片和快速切换的头像框添加背景
- UI调整
  - 取消每个属性的info按钮，将所有属性的描述整合到角色卡片页右上角的info按钮中逐条显示
  - 角色卡片页info按钮需要使用专属图标
  - 角色卡片页立绘和头像框同步更新稀有度背景底图
- 优化项
  - 角色卡片快速切页
    - 鼠标按住滑动时应自动切换为当前组件重心的角色卡片，并同步更新头像框的缩放和选中状态
    - 因此单次按下鼠标滑动时可能不止切换一个角色，需要自适应

## 版本修复BUG

- 暂无
