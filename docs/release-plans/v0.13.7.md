# v0.13.7 版本开发单

基准版本：[v0.13.6](v0.13.6.md)。状态：画面及节奏已完成，Unity 和后台验证通过，音频待素材。

## 版本开发内容

本版本目标：

- 新配置
  - 暂无
- 新素材
  - 制作追打时角色身上的光效，初步设想为灵光一闪的感觉，一瞬间的白光闪过
  - 从音频里选择合适的音效作为追打音效，类似不刺耳的短暂的“咻”或者“叮”之类的声音，后续多个角色一起上场可能频繁追打
  - 挑选0001Goku合适的音效并接入，包括技能、入场、受击等
- 新功能
  - 暂无
- UI调整
  - 战斗时角色的状态条改用圆角边框，且无特殊说明，项目中圆角边框>方形边框（素材制作规则）
- 优化项
  - 追打的衔接不需要留这么长的窗口时间，遵循演出时长上必杀>=普攻>>追打，普攻、技能和必杀演出较慢，但是追打链则很快
  - 追打动作出手前角色身上接入追打特效和音效

## 版本修复BUG

- 0001Goku必杀时立绘显示bug
- 0001Goku必杀尾部仍然没有淡出的效果，且有明显圆柱感，需要优化
