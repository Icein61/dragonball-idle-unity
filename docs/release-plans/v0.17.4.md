# v0.17.4 版本开发单

基准版本为 [v0.17.3](v0.17.3.md)。本版完成后台验收。

## 版本开发内容
  这个小版本版本的开发基本完毕了，完成这个中间版本的开发可以草拟下个小版本的开发单了。
本版本目标：

- 新配置
  - 暂无
- 新素材
  - 三种定位的素材重新设计，需要简洁干练，目前太油腻
- 新功能
  - 暂无
- UI调整
  - 角色页、角色卡片的定位图标高度和旁边的文本高度没对齐
  - 编队页角色卡片的定位高度和旁边的稀有度图标没对齐，并且间距需要略微缩小
  - 编队页和战场的每个阵位都是平行四边形，倾斜度略微增加且九个平行四边形形状大小都一样
- 优化项
  - 暂无
