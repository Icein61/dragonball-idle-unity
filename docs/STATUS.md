- 同名加成独立期限与队长专属乘区。

- 4档挑战与解锁、胜利掉落、自动重复、首胜奖励、离线素材、本地存档备份。
- 中文界面、暂停/倍速、事件日志；v0.1.1已有可见截图，本版尚未做可见画面验收。
- 自动测试、CI、可复现打包与版本对应规范。
- 20张角色原型、10张初始可用；PersonId/Stage/Form/Title/Rarity/Release与稳定CardId分离。
- 图鉴/筛选/详情、身份标签队长覆盖、候补换人、3组阵容预设。
- 定向装备与技能残页掉落、技能解锁、收藏筛选和装备差值比较。
- schema2按CardId迁移与迁移前独立备份；一张AI生成悟空视觉样片已入库。
