# v0.1.0 验证记录
日期：2026-11-13。这是技术Demo验收记录，不代表全部目标规格完成。

## 纯C#检查
Tools/validate-core.ps1运行166个断言，其中120个为4个难度各30个随机种子的完整战斗终止检查。
其余覆盖：六回合45/45/30/35/35/20%加成、临时贡献独立到期、同源重复、队长独立乘区、精确绝招冷却、眩晕机会与冷却区分、必杀额外插入、护盾与受击、闪避、索敌、重复卡、两个技能槽、装备实例、标签保持、基础数据操作、离线时间边界及确定性重放。
初始阵容每档30场胜利次数为30/30/30/0；第四档是构筑挑战，并非保证裸装通过。此数据不证明2～3小时成长节奏已经平衡。
未实现通用驱散/复活/多波/全部触发器等44项设计中的每一个分支，不能把166断言等同全部规格通过。

实际Windows Player使用独立测试存档执行完整首关胜利、奖励保存与重载。
可见窗口检查了菜单、战斗、结算及养成界面；初次隐藏窗口截图全黑，已判无效并改用用户授权的可见测试。
新增双技能槽与装备持久化检查，最终打包smoke会覆盖更多页面截图。
无运行时异常后才允许生成发布manifest；最终源码版本与包SHA256见Release附件。
