# v0.14 开发复盘

v0.14 从悟空的制作样板扩展到三张正式卡，建立了角色表、素材和 Unity 接入的完整流程。当前战斗 Demo 为中心对称 3v3，试阵可验证五、七、九人敌阵。上线范围以填写完成且标记上线的卡为准。

| 本阶段的返工点 | 后续沿用的做法 |
| --- | --- |
| 魔贯光杀炮的起手动画结束时，蓄力状态仍在持续。 | 让持续效果随战斗状态。检查起手、等待、其他角色行动、释放和退场。 |
| 远距离追打沿用统一的短演出时长，压缩了接近动作。 | 独立计算地面距离和步频。覆盖近、远、跨排，核对命中与回位时点。 |
| 图标的服装正确时仍可能看不清角色或动作。 | 用卡面核对时期和服装，在 64 像素检查双手、弹道和人物表情。 |
| 音轨散在旧来源中，重复定位费时。 | 使用统一索引，记录音轨相对路径、运行事件和源哈希。 |
| 单次演出通过后，追打链或满怒插入仍会触发状态衔接问题。 | 核心检查结算与存档，隔离 Player 回归正常流程和中断，Unity 渲染验证实际画面。 |

本阶段以 [v0.14.5](../release-plans/v0.14.5.md) 收尾。下一阶段的需求和优先级留在 [v0.15.0 开发单](../release-plans/v0.15.0.md)。
