# v0.13.0 九宫格试阵与数据接口

开发范围见[原开发单](../release-plans/v0.13.0.md)。本版把回合模拟与 Unity 表现分开：核心每次返回一个动作，试阵页可自动播放、暂停或单步查看。它是编队内无奖励验证入口，不是旧挑战系统。

我方从最右列开始，每列从上到下编号 1 至 9，敌方镜像。两侧按已占用阵位的编号分别排队，交替由我方先拿手位，剩余一侧顺延。手位数字只在模拟中保留；退场跳过原手位。每轮每名存活角色有一次普攻手位。下一动作前先处理满怒必杀；多个满怒按手位。必杀不会推进普攻游标。

配置入口：

| 功能 | 文件 | 字段 |
| --- | --- | --- |
| 角色 | [RoundKits.json](../../Assets/DragonIdle/Resources/Config/Characters/RoundKits.json) | 稳定 CardId；普攻／必杀／追打名和倍率；技能列表中填写名称、触发、效果、数值。C 一项技能，B/A/S 两项。 |
| 战斗 | [RoundEncounters.json](../../Assets/DragonIdle/Resources/Config/Battle/RoundEncounters.json) | 稳定 ID、标题、敌方属性倍率、九个位置的 CardId；留空使用空字符串。配置验证要求五至九人。 |

数据及索敌的代理默认：先找离中央最近的敌列，同列优先与攻击者相近的行，同值按手位。普攻出手得 35 怒气，未闪避且存活的受击者得 15；怒气上限 100。普攻会心后，由手位最早且本轮尚未追打的一位其他队友追击。行动技能可在普攻后按低生命条件追击或援助；被动在开场生效。必杀先于待处理的追打和行动技能。40 回合仍未分胜负时判平。测试卡沿用现有 HP、攻击、防御，临时招式与对战数值不等于正式角色方案。卡面战力重新以试阵属性计算，不计速度或旧系统加成。

存档继续兼容现有 v4 文件。旧队伍与预设原样留存；没有九宫格时，旧队按原槽顺序搬入前五名，原序号保留。首次编辑后用 CardId 保存一份独立阵位数组，旧第六人不会失去收藏、成长或装备。旧系统的代码和设计记录保留作迁移及历史参考，当前玩家入口封闭，不发旧系统奖励、不结算离线收益。未发放的卡仍保持未拥有状态。

战斗画面使用现有立绘、生命条与行动反馈。本版没有新动作图集、奖励机制或新角色内容。
