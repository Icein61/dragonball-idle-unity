# v0.6.0 角色图鉴实现

GalleryTheme.cs提供两种缓存的运行时圆角Sprite（控件14、面板24参考像素半径）与九宫格，像素由UI几何生成，不修改角色素材、不引入第三方UI框架。GalleryFocus用EventSystem的选择/取消事件显示焦点轮廓。按钮继承120ms色彩反馈，减少动效立即化。

CardLibrary和Detail分别作为列表与详情容器，公共顶栏/导航保持。列表四列，详情左侧全图、右侧信息、底部操作。图像始终完整UV与原比例显示；本轮采用完整图缩略图，不在未验收时默认裁切角色标志动作。

OpenGalleryCard仅更新当前选择并绘制详情；ReturnToCards恢复原列表和焦点，不重建网格。RefreshGallery只在结果ID及顺序变化时重建卡片，结果不变时更新上阵/持有状态并复用节点；培养排序或换阵导致顺序变化时仍正确重建。内容变更不影响检索和存档公式。

概览默认共用InspectCharacter显示当前编队有效属性，候补用个人值；statsExpanded展开原基础/个人/编队拆解。完整技能原文保持，代理数值解释单段列出。详情段落19号、标题20号，中文高度继续以实际UI.Text.preferredHeight测量。

弹窗复用同一主题、输入隔离与ESC逻辑；声音及角色上下文不改。编队/装备等其余页面的界面迁移属于后续阶段，现有接口继续保留。无窗口测试与可见验收分别记录。
