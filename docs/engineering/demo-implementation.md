# v0.1.0 实现说明
这是首个可玩技术切片，confirmed.md继续定义完整目标。本文件区分已实现范围与后续目标。

## 代码入口
- Assets/DragonIdle/Core/Combat.cs：纯C#模拟。Step推进至下一次事件，不读取Unity时间或动画。
- Assets/DragonIdle/Core/GameData.cs：八张测试卡、四难度、Profile、装备、技能、抽卡和离线素材。
- Assets/DragonIdle/Presentation/DemoGame.cs：中文界面、演出、存档事务和独立smoke模式。
- Assets/DragonIdle/Editor/BuildDemo.cs：创建可播放场景、锁定Windows构建参数并构建。
- Assets/DragonIdle/Scenes/Demo.unity：启动场景。打开后Play即可，无需手动放置组件。
- Tools/validate-core.ps1：使用Windows自带.NET Framework C#编译器运行逻辑检查。
- Tools/build-windows.ps1：验证后Unity构建。
- Tools/package-windows.ps1：干净源码构建、PC运行验证、ZIP及SHA256/manifest。
- .github/workflows/core-checks.yml：Windows CI逻辑验证，不需要Unity许可证。

## 本次默认数值（实验值，不是最终投放）
- 行动条阈值1，速度每模拟时间推进speed/1000；事件演出默认0.85秒，可倍速。
- 普攻倍率1，绝招1.14，必杀1.30；暴击1.5倍，基础暴击8%、闪避4%。
- 攻击乘区：基础攻击×队长×普通攻击强化×增幅×招式倍率×伤害强化。
- 防御使用100/(100+防御)，随后应用减伤；减伤在本版防御路径最多90%，特殊免疫待实现。
- 怒气上限/消耗100，普攻16、绝招28、受击7，必杀不产出手怒气。
- 必杀后自身攻击强化12%持续2次自身机会；支援角色另给队友6%两机会。
- 控制绝招命中眩晕1次机会；坦克绝招护盾15%最大生命；治疗绝招治疗最低生命比例队友14%。
- 一次修炼增加0.1%基础生命/攻击/防御，成本30起；共鸣每级0.4%。
- 普通护腕攻击1.2%、战斗服防御1.8%、稀有核心攻击5.5%；攻击珠0.8%。
- 每个胜利掉落1装备，8%稀有核心，20%额外珠；背包没有隐式回收或静默丢弃，完整筛选管理后续扩充。
- 暂未设置可分解按钮，避免误删物品。
- 三前四后固定坐标；同排最近按Y距离再槽位，镜头坐标不参与结算。

## 生命周期与保存
- Contribution记录独立到期机会，不合并计时器；永久贡献用整场标识。
- 机会开始增加计数；结束过期。机会内新施加按接下来机会计时。
- 正常行动完成减少既有冷却，施放绝招设置新冷却不在当次减少。
- 存档schemaVersion=1，正式用户存档在Unity persistentDataPath/profile-v1.json。
- 写临时文件后替换，保留profile-v1.json.bak；操作失败时还原内存数据。
- 战斗不做中途断点续战；退出当前战斗无损失，下次重开，不重复发放胜利奖励。
- 离线收益进OfflineBank，领取后清零；打开时结算、运行中每分钟更新最后在线时间、退出时更新。活跃游玩不会每小时重复发离线奖励。
- 读取失败保留原文件并禁用进度写入；本版需手工从bak恢复，尚未提供自动恢复UI。
- smoke使用独立-savePath，不改用户正式存档。
