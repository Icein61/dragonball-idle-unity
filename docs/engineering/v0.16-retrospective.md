# v0.16 开发复盘

v0.16.0 建立固定基础属性、潜力成长和满级独立随机 Demo。v0.16.1 接入拉蒂兹，修复比克闪避反击并让角色表累计追打状态。v0.16.2 收尾角色卡背景、属性说明和连续拖动。

## 版本称呼

按用户约定，`v0.16.2` 的 `0` 是大版本号，`16` 是小版本号，`2` 是中间版本号。小版本从中间版本号 `0` 开始，本阶段结束后建立 `v0.17.0` 开发单。

## 经验

- 图鉴拖动与内容更新需要分别保留状态。拖动由头像条持续接收，跨过中心时才更新正文。以同一次按住操作验证逐次切卡、反向切回和两端边界，单独模拟松手不足以覆盖这类交互。
- 色板从现有角标取色，生成的纹理保留浅淡和空白中心。底图复用同一资源映射，四档都要实际导入测试。技能图标优先核对手指、腕部和动作轮廓，再检查在技能页及战斗名牌尺寸下是否清楚。
- 角色表同步要能重复执行。配置、图标资源路径和嵌入立绘分别检查，稳定 CardId 仍是旧档与阵容的依据。
- 验证记录分别写明逻辑、Unity 画面与 Windows Player。短期反击次数和闪避断链用固定夹具。随机 Demo 用种子复现。保留试玩包校验和及构建来源。
