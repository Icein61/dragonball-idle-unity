# v0.15.4 角色素材制作记录

## 0005 克林

稳定 CardId 为 `krillin-test`。设计使用 [角色工作簿](../../../outputs/character/character.xlsx)「角色设计」第 61 至 73 行。
参考视频包括多林连击、气圆斩、散射后退、战前动员、移动与站立待机。参考视频用于核对动作、方向和节拍。
立绘、图标和动作图集均使用与现有角色一致的 C 版手绘漫画画风。

| 素材 | 选择和运行资源 |
| --- | --- |
| 立绘 A | [沉着举盘](krillin-portrait-a.png)，用户选定。运行资源 `Art/V0154/Krillin/portrait`。 |
| 立绘 B | [掷出前蓄势](krillin-portrait-b.png)。 |
| 图标 A | [近景构图](krillin-icons-a.png)，用户选定。运行资源 `Art/V0154/Krillin/skill-icons`。 |
| 图标 B | [动作轮廓](krillin-icons-b.png)。 |
| 动作与状态 | `combat-poses` 和 `reactions` 共 18 张图，含待机、入场、贴地接近、撤回、四项招式、五种受击和战败。 |
| 特效 | 多林连击三个接触点、气圆斩的盘成形与飞行及整列命中、散射后退十个独立飞行与命中窗口、战前动员暖金扩散。 |

图标从左上起按行读，分别为多林连击、气圆斩、散射后退、战前动员。裁切位置在 `RoundKits.json`。
[候选一览](krillin-candidates.jpg)。[Unity 后台画面](../../../.validation/editor-frames-v0154)。

## 0001 悟空、0002 贝吉塔

两个角色从各自参考视频提炼前脚落地、后腿推蹬和左右交替动作，分别绘制四张连续跑动姿势。
运行资源为 `Art/V0154/Goku/run-cycle` 和 `Art/V0154/Vegeta/run-cycle`。接近时按本招式起手时长分配四帧，脚底锚点按每个姿势校准。
