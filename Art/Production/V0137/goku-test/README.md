# v0.13.7 追打与悟空必杀演出

## 追打

- 自动轮转检查队列里实际能执行的下一动作。下一动作是追打时，衔接从 780 毫秒降到 75 毫秒。满怒必杀优先及失效追打的跳过规则沿用战斗核心。
- 追打共 390 毫秒。前 86 毫秒角色停在出手起点，白色短光斜掠胸口。白光收掉后开始动作，悟空上勾拳在约 190 毫秒处命中。命中前生命、护盾和怒气继续显示上一帧快照。普通动作、技能及必杀沿用完整演出时长。
- 追打起手接入 `pursuit-start` 音频事件。角色当前档的完整 [音频配置](../../../../Assets/DragonIdle/Resources/Config/Characters/GokuAudio.json) 有 18 个事件，资源路径均留白。

## 0001Goku 必杀

- v0.13.6 的六格原图是 1536×1024，Unity 导入设置会把宽度转换到相邻的二次幂，导致同一组矩形按不同采样坐标取图。现按原始尺寸导入，并保持输入透明度及无压缩，六格的裁切区域保持与原图一致。
- 光波保留动作方向和距离。蓝白亮芯外是带扰动的多层柔边，前端沿发射方向渐细。到达后先减弱远端，再向掌心收拢亮度。收手阶段继续淡出，伤害结算仍发生在光波抵达时。
- 阵位三条状态轨道与填充统一使用圆角端点，依次为绿色生命、蓝色护盾、橙色怒气。

## 音频规则

按用户最新指示，项目音效从指定的《Dragon Ball Xenoverse 2》音频库查找。目录内的悟空语音、打击、格挡和蓄气文件是原游戏导出音轨，作为制作参考。追打提示、悟空技能、入场和受击的运行事件标为留白。
