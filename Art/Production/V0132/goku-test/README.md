# 0001Goku 受击、进场与战败

简表编号为 `0001Goku`，对应已有运行 `CardId` `goku-test`。参考 [v0.13.1 已确认角色动作](../../V0131/goku-test/README.md)的画风、道服、赤足与脚底基准。三个透明原画 PNG 和原创高原场景使用内置图像生成工具制作。

[运行时动作表](../../../../Assets/DragonIdle/Resources/Art/V0132/Goku/Reaction.json)使用 16 张源姿势，5 段受击约 0.34–0.76 秒，进场 0.99 秒，战败 1.06 秒。每次实际命中从当前位移采样并短暂承接旧姿势，再进入新段。可以连续从同一状态受击，也可以从任意状态进入其他状态。为了预览击退追打，在 1v1 的击退段结束后保留一小段落点位移，再从该位置起算追打。普通试阵的数值和手位规则保持沿用。

声音为 6 条普通话合成占位语音和 9 个原创合成音效。[龟派气功原作招式说明](https://en.dragon-ball-official.com/news/01_140.html)用于聚气至释放的段落设计。语音由 Windows Microsoft Kangkang 合成，按聚气、出手、起势和命中点编排。源 WAV 位于 [audio](audio)，可通过[语音脚本](../../../../Tools/synth-goku-duel-voice.ps1)和[音效脚本](../../../../Tools/synth-goku-duel-fx.py)重新生成到指定目录。实机观感和试听留待试玩。

## 图像制作依据

受击表以既有待机及格斗全身图为模型参考，采用同一三分之四朝向和六格构图。过渡表直接参考新受击表与已确认待机，以四格补肩胸压缩、空中收膝、落地与起身。进场战败表参照同一服装和比例，分为跃入、落地、立稳、失衡、跪撑、侧卧。战场使用雾白天空、低位岩台和留有较大交手空间的浅色平地。图中角色和背景分别导入。
