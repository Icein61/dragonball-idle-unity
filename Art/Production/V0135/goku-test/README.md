## 参考录屏音效

按动作接触点截取候选时间窗，在内存中解码原始录屏，检查左右声道、中心及侧声道和 180–5200 Hz 频带。以下数字是该处理输出的相对满幅 RMS，单位 dBFS。源文件完整保留。

| 源片段 | 尝试结果 |
| --- | --- |
| `0001Guku普攻.mp4` 0.135–0.245、0.401–0.491、0.878–0.991 秒 | 中心峰段约 −25、−25、−23 dBFS，侧声道约 −120 dBFS。拳脚峰值能定位，左右声道抵消后几乎只剩数字静音。 |
| `0001Goku追打.mp4` 0.205–0.340 秒 | 中心约 −26 dBFS，侧声道约 −84 dBFS。存在微弱声道差，约低 58 dB，未形成可用的独立命中声。 |
| `0001Goku必杀.mp4` 0.550–0.810、0.940–1.200、1.420–1.820 秒 | 聚气窗中心约 −42 dBFS，放射窗约 −25 dBFS。侧声道均约 −120 dBFS。放射后的能量延续为连续混音，没有独立轨可选。 |
| `0001Goku防御.mp4` 0.170–0.670 秒内的三个候选窗 | 侧声道约 −31 至 −32 dBFS，相邻窗已有相近的持续声音，滤波和裁剪后未得到独立架挡音。 |
| `0001Goku待机.mp4` | 双声道解码结果为静音，作为视觉参考。 |
