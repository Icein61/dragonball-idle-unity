# 0001Goku v0.13.3 动作、特效与音频

简表编号 `0001Goku` 对应 `CardId` `goku-test`。「角色设计」C11/E11/H11、C12/E12、C13/E13、C14/E14/H14 分别记录普攻、必杀、追打和被动。表内指定的效果与演出优先，空缺参考五段视频。角色造型、道服和脚底基准沿用已确认的 C 版手绘风格。

## 视频与演出

参考源位于本地工程 `Assets/DragonIdle/Resources/Videos`。逐段检查动作和音频峰值，五个源文件的 SHA-256 与制作前一致。

| 本地参考 | 观察与接入 |
| --- | --- |
| `0001Goku待机.mp4`（3.69 秒） | 亮出前掌，重心轻移后回到警戒。站立循环 3.69 秒，另有 1.80 秒的偶发换势。 |
| `0001Guku普攻.mp4`（1.27 秒） | 0.165 秒与 0.442 秒为两拳接触点。倒地分支在 0.905 秒扫腿并显示伤害与倒地。普通分支只在第二拳显示伤害。 |
| `0001Goku追打.mp4`（0.51 秒） | 从短促压低重心接上勾拳。0.250 秒接触并使目标小浮空，接着收拳回位。目标从倒地的当前位置接起。 |
| `0001Goku必杀.mp4`（4.50 秒） | 0.570 秒开始聚气，0.980 秒推出，气团沿目标方向飞行，1.620 秒到达时结算横排，随后光束衰减，2.690 秒完成收招。 |
| `0001Goku防御.mp4`（6.98 秒） | 采用抬肘举臂、受力、放松的轮廓为 1v1 防御预备段，实际受击交给命中的状态段。 |

三个透明 PNG 在同一批准造型基础上绘制，新增 18 张姿势。[运行时动作表](../../../../Assets/DragonIdle/Resources/Art/V0133/Goku/Motion.json)共使用 67 张姿势、8 条动作轨。扫腿、被动热身及已确认的「修炼的成果」图标沿用批准素材。五种受击、进场和战败沿用 [v0.13.2 制作记录](../../V0132/goku-test/README.md)，上勾拳从倒地姿势和位移起算。

拳脚、扫腿、上勾拳和架挡用接触点触发独立特效。龟派气功分聚气、推出气团、飞行、贯通光束和衰减。17 条 [WAV](audio) 含 6 条普通话合成语音和 11 条原创合成音效，按起势、接触、聚气、推出、命中、落地分配。可用[语音脚本](../../../../Tools/synth-goku-duel-voice.ps1)的 `-ReferenceTiming` 和[音效脚本](../../../../Tools/synth-goku-duel-fx.py)的 `--reference-timing` 再生成。

视频仅用于制作参考。Windows 构建以临时工程排除这一目录，独立使用已导入的姿势、音效和运行时特效。[Unity Resources 系统](https://docs.unity3d.com/cn/current/Manual/assets-resources-system-load.html)

后台检查验证 18 张新增姿势的透明边界、长度和相位、17 条 WAV 的导入与触发、25 种受击过渡和参考视频排除。实机画面与语音听感待试玩。
