右拳从近侧肋部直达腹部高度，另一拳护颊。扫堂腿的脚踝与膝部朝向一致，撑手落在肩下。[被动新版图标](passive-training.png)同时呈现握腕手势、悟空面部和腰部以上道服，其他三个招式沿用[原图标图集](skill-icons.png)。

新选用 33 张人物姿势，连同原有可用姿势组成 49 张预览源姿势。独立图集与单张源稿保留 RGBA。人物位置、各帧原图范围和命中锚点见 [motion-art.js](motion-art.js)，出帧和节奏见 [motion-timing.js](motion-timing.js)。起手短线、命中扩散、扫腿弧、聚气粒子和光束使用连续时间渲染。新增素材使用内置图像生成，见[参考与提示词](motion-prompts.json)。

时长和龟派气功的聚气、推出、收招是制作默认值，简表 H12 仍待填写。完整动作预览已获用户确认，Unity 已按[技能素材规范](../../../../docs/standards/art/skill-assets.md)接入。正式战斗前还需核对普攻概率、扫堂腿提示与「击退」追打的关系，以及「劲敌」类别角色归属。

## Unity 接入

九宫格的 `goku-test` 双方镜像，站立约每 12 秒有一次松握拳。普攻、必杀和追打由各自的回合动作触发。扫堂腿沿用当前试阵已排入追打的结果。左拳与第二拳各有动作和命中提示，整次普攻只显示一次模拟结算。有扫腿时在扫腿命中显示结算。开场被动动画按固定手位依次呈现，开场加成由战斗初始化处理。

[资源同步脚本](../../../../Tools/sync-goku-round-art.mjs)从已确认的浏览器动作数据生成 Unity 动作清单，并复制选用的 PNG。运行资源在 [V0131/Goku](../../../../Assets/DragonIdle/Resources/Art/V0131/Goku/Motion.json)。暂停冻结，单步可播放一段，演出中继续单步按钮会结束当段。减少动效时保留静态站姿和正常读数。

无图形 Player 已验证动画数据、UI 节点、特效几何和命中时点，实际画面待试玩。
